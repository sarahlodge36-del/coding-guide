# XGENFUTBOT — Interactive Coding Guide

An interactive web development learning guide created to help beginners understand coding through structured lessons, practical examples and exercises.

## About the Project

XGENFUTBOT is a personal learning project that I developed while building my own web development skills.

The aim was to create an accessible resource where beginners can explore coding concepts, follow lessons and practise what they learn.

The project is divided into two connected sections:

Free Coding Guide: Introductory lessons covering foundational web development concepts, supported by cheat sheets and quizzes.

Extended Learning Section: A separate learning prototype featuring additional chapters and topics, with an experimental payment and member-access flow.

## Features

Structured coding chapters

Beginner-friendly explanations

Practical learning resources and cheat sheets

Quizzes to reinforce understanding

Navigation between lessons

Separate extended-learning section

## Development Notes

The extended-learning section was created as an experiment to understand payment setup and password-based access.

Its current browser-based authentication is a learning prototype and is not suitable for protecting commercial paid content. A production version would require secure server-side authentication, payment verification and access controls.
