What is a Table?

A table represents information in a grid format. There are several types of information that work best displayed in a grid — for example sports results, financial reports, or TV schedules. Each block in the grid is referred to as a table cell. In HTML a table is written out row by row.

Basic Table Structure

  • <table> — creates the table
  • <tr> — table row
  • <td> — table data (each cell)
<table>
  <tr>
    <td>Monday</td>
    <td>Tuesday</td>
    <td>Wednesday</td>
  </tr>
  <tr>
    <td>HTML</td>
    <td>CSS</td>
    <td>JavaScript</td>
  </tr>
</table>

Table Headings

The th tag represents a heading for a column or row. Use the scope attribute with values row or col to indicate which direction the heading applies.

<tr>
  <th scope="col">Name</th>
  <th scope="col">Age</th>
</tr>

Spanning Columns and Rows

colspan makes a cell stretch across more than one column. rowspan makes a cell stretch down across more than one row.

<td colspan="2">Spans two columns</td>
<td rowspan="2">Spans two rows</td>

Long Tables — thead, tbody, tfoot

For longer tables you can split the content into three sections — a header, a body, and a footer. This helps the browser and screen readers understand the structure.

  • <thead> — the table header row
  • <tbody> — the main body of the table
  • <tfoot> — the footer row

🔨 Now Let's Build!

Open your index.html file in Notepad. We're going to add a simple table to it. Add the following code after your existing content inside the body tags:

<h2>My Weekly Schedule</h2>
<table>
  <tr>
    <th>Day</th>
    <th>Activity</th>
  </tr>
  <tr>
    <td>Monday</td>
    <td>HTML</td>
  </tr>
  <tr>
    <td>Tuesday</td>
    <td>CSS</td>
  </tr>
  <tr>
    <td>Wednesday</td>
    <td>JavaScript</td>
  </tr>
</table>

Save and refresh your browser. You should see a basic table on your page!

file:///C:/Users/Home/index.html

Day Activity
