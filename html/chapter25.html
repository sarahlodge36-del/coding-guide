How Events Work

Events are things that happen in the browser — a user clicking a button, moving their mouse, pressing a key, submitting a form, or a page finishing loading. JavaScript can listen for these events and run code in response to them.

This is the mechanism that makes everything interactive. Without events, JavaScript would just run once when the page loads and stop. Events allow JavaScript to keep responding to the user for as long as the page is open.

Every event has three parts — the element it happens on, the type of event, and the function to run when it happens.

Event Listeners

The modern way to handle events is addEventListener. You call it on an element, tell it what type of event to listen for, and give it a function to run when that event fires.

var btn = document.getElementById('startBtn');

btn.addEventListener('click', function() {
  alert('Button clicked!');
});

The function passed into addEventListener is called a callback function — it gets called back when the event fires. You can write it inline like above, or define it separately and pass the name in.

function handleClick() {
  alert('Button clicked!');
}

btn.addEventListener('click', handleClick);

Notice there are no parentheses after handleClick when passing it in. You're passing the function itself — not calling it. If you wrote handleClick() with parentheses it would run immediately rather than waiting for the click.

The Event Object

When an event fires, JavaScript automatically creates an event object containing information about what happened. You can access this by giving your callback function a parameter — conventionally called e or event.

btn.addEventListener('click', function(e) {
  console.log(e.target); // the element that was clicked
  console.log(e.type); // 'click'
  console.log(e.target.id); // the id of the clicked element
});

e.target is particularly useful — it tells you exactly which element triggered the event. You've already been using this in the game when you check e.target.tagName and e.target.getAttribute('data-index').

Event Delegation

Rather than adding an event listener to every button individually, you can add one listener to a parent element and let events bubble up to it. This is called event delegation and it's much more efficient — especially when you're creating elements dynamically.

// Instead of this — adding a listener to every button:
btn1.addEventListener('click', handleClick);
btn2.addEventListener('click', handleClick);
btn3.addEventListener('click', handleClick);

// Do this — one listener on the parent:
document.getElementById('choices').addEventListener('click', function(e) {
  if (e.target.tagName === 'BUTTON') {
    handleClick(e);
  }
});

This is exactly what the game uses — one listener on the choices div catches clicks on any button inside it. Because the buttons are created dynamically by showChoices(), you can't add listeners to them directly — they don't exist yet when the page loads.

Common Event Types

  • click — user clicks an element
  • dblclick — user double clicks an element
  • mouseover — user moves mouse over an element
  • mouseout — user moves mouse away from an element
  • keydown — user presses a key
  • keyup — user releases a key
  • keypress — user presses and releases a key
  • submit — user submits a form
  • change — value of an input changes
  • focus — element receives focus
  • blur — element loses focus
  • load — page or image finishes loading
  • DOMContentLoaded — HTML is loaded and parsed

Keyboard Events

Keyboard events fire when the user presses a key. The event object tells you which key was pressed.

document.addEventListener('keydown', function(e) {
  console.log(e.key); // 'Enter', 'a', 'ArrowUp' etc
  console.log(e.keyCode); // numeric key code
});

// Listen for the Enter key specifically
input.addEventListener('keypress', function(e) {
  if (e.key === 'Enter') {
    startGame();
  }
});

Preventing Default Behaviour

Some elements have default browser behaviour when events fire on them — links navigate to a URL, form submit buttons reload the page. You can stop this with preventDefault().

document.getElementById('myForm').addEventListener('submit', function(e) {
  e.preventDefault(); // stops the page reloading
  // handle the form data with JavaScript instead
});

// GAME VARIABLES
var playerName = '';
var playerHealth = 3;
var playerScore = 0;
var inventory = [];
var currentRealm = 0;

// REALM DATA
var realms = [
  { name: 'The HTML Vault', guardian: 'The Tag Keeper', reward: 'Structure Crystal', rewardIcon: '💎', question: 'What does HTML stand for?', options: ['Hypertext Markup Language', 'High Transfer Machine Language', 'Hypertext Making Language', 'Hyper Transfer Markup Language'], correct: 0 },
  { name: 'The CSS Labyrinth', guardian: 'The Style Witch', reward: 'Style Gem', rewardIcon: '🔮', question: 'Which CSS property makes text bold?', options: ['font-style: bold', 'text-weight: bold', 'font-weight: bold', 'bold: true'], correct: 2 },
  { name: 'The JavaScript Jungle', guardian: 'The Logic Beast', reward: 'Logic Core', rewardIcon: '⚡', question: 'What is the correct way to declare a variable in JavaScript?', options: ['variable name = 5', 'var name = 5', 'v name = 5', 'declare name = 5'], correct: 1 },
  { name: 'The Server Caves', guardian: 'The Dark Server', reward: 'Power Cell', rewardIcon: '🔋', question: 'What does DOM stand for?', options: ['Document Object Model', 'Data Object Method', 'Document Oriented Markup', 'Dynamic Object Model'], correct: 0 },
  { name: 'The Cloud Tower', guardian: 'The Glitch', reward: 'Cloud Key', rewardIcon: '🗝️', question: 'Which event fires when a user clicks a button?', options: ['onpress', 'ontouch', 'click', 'onbutton'], correct: 2 }
];

// DOM FUNCTIONS
function showMessage(text) { document.getElementById('message').textContent = text; }
function showStory(text) { document.getElementById('story').textContent = text; }

function updateHealthBar() {
  for (var i = 1; i <= 3; i++) {
    var heart = document.getElementById('heart' + i);
    if (i <= playerHealth) { heart.classList.remove('heart-lost'); }
    else { heart.classList.add('heart-lost'); }
  }
}

function updateInventory() {
  var itemsDiv = document.getElementById('inventory-items');
  itemsDiv.innerHTML = '';
  for (var i = 0; i < inventory.length; i++) {
    var item = document.createElement('span');
    item.className = 'inventory-item';
    item.textContent = inventory[i].icon + ' ' + inventory[i].name;
    itemsDiv.appendChild(item);
  }
}

function updateScore() { document.getElementById('score-display').textContent = 'Score: ' + playerScore; }

function showChoices(choices) {
  var choicesDiv = document.getElementById('choices');
  choicesDiv.innerHTML = '';
  for (var i = 0; i < choices.length; i++) {
    var btn = document.createElement('button');
    btn.textContent = choices[i];
    btn.setAttribute('data-index', i);
    choicesDiv.appendChild(btn);
  }
}

function fadeAndRun(callback) {
  var game = document.getElementById('game');
  game.classList.add('fading');
  setTimeout(function() { callback(); game.classList.remove('fading'); }, 300);
}

// GAME FUNCTIONS
function startGame() {
  var nameInput = document.getElementById('nameInput').value.trim();
  if (nameInput === '') {
    showMessage('You need to enter your name, coder!');
  } else {
    playerName = nameInput;
    document.getElementById('input-area').style.display = 'none';
    document.getElementById('health-bar').style.display = 'block';
    document.getElementById('inventory-panel').style.display = 'block';
    document.getElementById('score-display').style.display = 'block';
    updateHealthBar();
    updateScore();
    showStory('Welcome, ' + playerName + '. I am XGENFUTBOT — your guide, your conscience, and occasionally your biggest critic. The Code Machine has been dismantled and its five components scattered across five dangerous realms. You must retrieve them all. Do you have what it takes?');
    showMessage('');
    showChoices(['I was born ready. Let\'s go.', 'I\'m terrified but let\'s do this anyway.']);
    document.getElementById('choices').setAttribute('data-mode', 'intro');
  }
}

function enterRealm() {
  var realm = realms[currentRealm];
  showStory('You enter ' + realm.name + '. The ' + realm.guardian + ' blocks your path. "Answer my question and the ' + realm.reward + ' is yours," it growls.');
  showMessage(realm.question);
  showChoices(realm.options);
  document.getElementById('choices').setAttribute('data-mode', 'question');
}

function handleAnswer(index) {
  var realm = realms[currentRealm];
  if (index === realm.correct) {
    inventory.push({ name: realm.reward, icon: realm.rewardIcon });
    playerScore += 100;
    updateInventory();
    updateScore();
    currentRealm++;
    if (currentRealm < realms.length) {
      showStory('Correct! The ' + realm.reward + ' ' + realm.rewardIcon + ' is yours. XGENFUTBOT nods approvingly. "Not bad. But there are ' + (realms.length - currentRealm) + ' realm' + (realms.length - currentRealm === 1 ? '' : 's') + ' left. Don\'t celebrate yet."');
      showMessage('');
      showChoices(['Continue to the next realm']);
      document.getElementById('choices').setAttribute('data-mode', 'continue');
    } else { endGame(); }
  } else {
    playerHealth--;
    updateHealthBar();
    if (playerHealth === 0) {
      gameOver();
    } else {
      showStory('Hmm — not quite. But that\'s completely fine. Nobody gets everything first time. The important thing is that now you\'ve seen the right answer, it\'ll stick. You have ' + playerHealth + ' ' + (playerHealth === 1 ? 'life' : 'lives') + ' remaining. Try again!');
      showMessage(realm.question);
      showChoices(realm.options);
      document.getElementById('choices').setAttribute('data-mode', 'question');
    }
  }
}

function gameOver() {
  showStory('Hey — don\'t feel bad about this. Seriously. The fact that you got this far means you\'re already doing brilliantly. The section that tripped you up is worth one more read — not because you\'re behind, but because once it clicks it clicks forever.');
  showMessage('XGENFUTBOT tips his fedora. "Every developer has been exactly where you are right now. Every single one."');
  showChoices(['Try again from the beginning']);
  document.getElementById('choices').setAttribute('data-mode', 'restart');
}

function endGame() {
  var ending;
  if (playerHealth === 3) { ending = 'PERFECT RUN! The Code Machine roars to life, all five components locked in place. XGENFUTBOT does an actual victory dance. "I knew you had it. Full marks, full lives, full brilliance. You are ready for what comes next." 🎉'; }
  else if (playerHealth === 2) { ending = 'The Code Machine activates — a few sparks fly but it works. XGENFUTBOT nods. "Solid run. One stumble does not a failure make. You\'re ready." ⚡'; }
  else { ending = 'The Code Machine splutters to life. XGENFUTBOT raises an eyebrow. "It works. Barely. But it works. Go back and review the bits that caught you out — then you\'ll be genuinely ready." 🔧'; }
  showStory(ending);
  showMessage('🎉 Quest Complete! Final Score: ' + playerScore + ' | Built with JavaScript.');
  document.getElementById('choices').innerHTML = '';
}

// EVENT LISTENERS
document.getElementById('startBtn').addEventListener('click', startGame);

document.getElementById('nameInput').addEventListener('keypress', function(e) {
  if (e.key === 'Enter') { startGame(); }
});

document.getElementById('choices').addEventListener('click', function(e) {
  if (e.target.tagName !== 'BUTTON') return;
  var mode = document.getElementById('choices').getAttribute('data-mode');
  var index = parseInt(e.target.getAttribute('data-index'));
  if (mode === 'intro') { fadeAndRun(enterRealm); }
  else if (mode === 'question') { handleAnswer(index); }
  else if (mode === 'continue') { fadeAndRun(enterRealm); }
  else if (mode === 'restart') {
    playerHealth = 3; playerScore = 0; inventory = []; currentRealm = 0;
    updateHealthBar(); updateInventory(); updateScore();
    fadeAndRun(enterRealm);
  }
});
