JavaScript

Advanced Cheat Sheet

Modern JavaScript reference. This is the good stuff. 😎

ES6 Variables

  • let name = 'Sarah'; — block scoped, can be changed
  • const name = 'Sarah'; — block scoped, cannot be reassigned
  • var name = 'Sarah'; — function scoped, legacy
  • Prefer const by default, use let when the value needs to change, avoid var in modern code

Arrow Functions

  • const greet = (name) => { return 'Hello ' + name; } — full arrow function
  • const greet = name => 'Hello ' + name; — implicit return, no braces needed
  • const greet = () => 'Hello!'; — no parameters
  • const add = (a, b) => a + b; — multiple parameters
  • arr.forEach(item => console.log(item)); — as a callback

Template Literals

  • `Hello ${name}!` — embeds a variable in a string
  • `${2 + 2}` — embeds an expression
  • `${isLoggedIn ? 'Welcome' : 'Please log in'}` — embeds a ternary
  • Use backticks ` not quotes
  • Can span multiple lines without escape characters

Destructuring

  • const [a, b, c] = [1, 2, 3]; — array destructuring
  • const [first, ...rest] = [1, 2, 3, 4]; — rest in destructuring
  • const { name, age } = person; — object destructuring
  • const { name: playerName } = person; — rename while destructuring
  • const { name = 'Unknown' } = person; — default value
  • function greet({ name, age }) { } — destructuring in parameters

Spread and Rest

  • [...arr1, ...arr2] — merges two arrays
  • [...arr] — copies an array
  • { ...obj1, ...obj2 } — merges two objects
  • { ...obj, name: 'Sarah' } — copies object and overrides a property
  • Math.max(...numbers) — spreads array as function arguments
  • function log(...args) { } — rest collects all arguments into array

Array Methods

  • arr.map(item => item * 2) — transforms every item, returns new array
  • arr.filter(item => item > 10) — returns items that pass the test
  • arr.reduce((total, item) => total + item, 0) — reduces to single value
  • arr.find(item => item.id === 5) — returns first matching item
  • arr.findIndex(item => item.id === 5) — returns index of first match
  • arr.some(item => item > 10) — true if any item passes
  • arr.every(item => item > 0) — true if all items pass
  • arr.includes('value') — true if value exists in array
  • arr.flat() — flattens nested arrays one level
  • arr.sort((a, b) => a - b) — sorts numerically ascending
  • arr.sort((a, b) => b - a) — sorts numerically descending
  • [...new Set(arr)] — removes duplicates from array

Objects

  • Object.keys(obj) — returns array of property names
  • Object.values(obj) — returns array of property values
  • Object.entries(obj) — returns array of [key, value] pairs
  • Object.assign({}, obj1, obj2) — merges objects
  • Object.freeze(obj) — prevents object from being modified
  • 'name' in obj — checks if property exists
  • const key = 'name'; obj[key] — dynamic property access

Promises

  • new Promise((resolve, reject) => { }) — creates a promise
  • promise.then(data => { }) — runs when promise resolves
  • promise.catch(error => { }) — runs when promise rejects
  • promise.finally(() => { }) — runs regardless of outcome
  • Promise.all([p1, p2, p3]) — resolves when all promises resolve
  • Promise.race([p1, p2]) — resolves when first promise resolves
  • Promise.allSettled([p1, p2]) — resolves when all settle

Fetch API

  • fetch('url') — makes a GET request, returns a promise
  • fetch('url').then(r => r.json()) — parses JSON response
  • fetch('url').then(r => r.text()) — parses text response
  • response.ok — true if status code is 200-299
  • response.status — the HTTP status code

async / await

  • async function name() { } — declares an async function
  • const name = async () => { } — async arrow function
  • const data = await fetch('url'); — waits for promise to resolve
  • await can only be used inside an async function
  • try { await ... } catch (e) { } — error handling with async/await

Error Handling

  • try { } catch (error) { } — catches errors
  • try { } catch (error) { } finally { } — finally always runs
  • error.message — the error message
  • error.name — the error type
  • throw new Error('Something went wrong'); — throws a custom error

localStorage

  • localStorage.setItem('key', 'value'); — saves a string
  • localStorage.getItem('key'); — reads a value
  • localStorage.removeItem('key'); — removes one item
  • localStorage.clear(); — removes everything
  • localStorage.setItem('key', JSON.stringify(obj)); — saves an object
  • JSON.parse(localStorage.getItem('key')); — reads an object
  • localStorage persists after the browser is closed
  • sessionStorage works the same but clears when the tab closes

Modules

  • export function greet() { } — named export
  • export const name = 'Sarah'; — named export of a variable
  • export default function greet() { } — default export
  • import { greet } from './module.js'; — named import
  • import greet from './module.js'; — default import
  • import * as utils from './utils.js'; — imports everything
  • <script type="module" src="main.js"></script> — enables modules in HTML

Useful Tricks

  • condition ? 'yes' : 'no' — ternary operator
  • value ?? 'default' — nullish coalescing
  • obj?.name — optional chaining
  • !!value — converts any value to boolean
  • +value — converts string to number
  • `${value}` — converts anything to string
  • setTimeout(() => { }, 1000); — runs after delay in ms
  • setInterval(() => { }, 1000); — runs repeatedly every ms
  • clearTimeout(id); — cancels a timeout
  • clearInterval(id); — cancels an interval
  • JSON.stringify(obj); — converts object to JSON string
  • JSON.parse(str); — converts JSON string to object
  • console.log(); — logs to console
  • console.error(); — logs error to console
  • console.table(arr); — displays array as a table in console
