The Basics

  • // single line comment
  • /* multi line comment */
  • var name = 'Sarah'; — declares a variable
  • let score = 0; — modern variable, can be changed
  • const gameName = 'Quest'; — constant, never changes
  • console.log('hello'); — prints to the browser console

Data Types

  • var name = 'Sarah'; — string (text in quotes)
  • var score = 100; — number
  • var gameOver = false; — boolean (true or false)
  • var inventory = []; — array (list of values)
  • var player = {}; — object

Strings

  • 'Hello' + ' ' + 'World' — concatenation joins strings
  • 'Hello'.length — number of characters
  • 'hello'.toUpperCase() — converts to uppercase
  • 'HELLO'.toLowerCase() — converts to lowercase
  • 'hello world'.includes('world') — returns true or false

Numbers

  • + — addition
  • - — subtraction
  • * — multiplication
  • / — division
  • ++ — adds 1 to a variable
  • -- — subtracts 1 from a variable
  • += — adds a value to a variable: score += 10
  • Math.random() — random number between 0 and 1
  • Math.floor() — rounds down to nearest integer
  • parseInt('5') — converts a string to a number

Arrays

  • var items = ['a', 'b', 'c']; — creates an array
  • items[0] — accesses first item (index starts at 0)
  • items.length — number of items in the array
  • items.push('d') — adds item to the end
  • items.pop() — removes last item
  • items.join(', ') — joins all items into a string
  • items.indexOf('b') — finds index of an item

Objects

  • var player = { name: 'Sarah', health: 3 }; — creates an object
  • player.name — accesses a property using dot notation
  • player['name'] — accesses a property using bracket notation
  • player.health = 2; — updates a property
  • this — refers to the current object inside a method

Functions

  • function greet() { } — declares a function
  • greet(); — calls a function
  • function greet(name) { } — function with a parameter
  • greet('Sarah'); — calls with an argument
  • return value; — sends a value back from the function
  • var result = greet('Sarah'); — stores the returned value

Comparison Operators

  • === — strictly equal (same value AND type)
  • !== — strictly not equal
  • > — greater than
  • < — less than
  • >= — greater than or equal to
  • <= — less than or equal to

Logical Operators

  • && — AND — both conditions must be true
  • || — OR — at least one condition must be true
  • ! — NOT — reverses a boolean

Conditionals

  • if (condition) { } — runs if condition is true
  • if (condition) { } else { } — runs else if false
  • else if (condition) { } — checks another condition
  • switch (value) { case x: break; } — checks multiple cases

Loops

  • for (var i = 0; i < 5; i++) { } — runs a set number of times
  • while (condition) { } — runs while condition is true
  • for (var i = 0; i < arr.length; i++) { } — loops through an array
  • break; — exits a loop early
  • continue; — skips the current iteration

DOM — Accessing Elements

  • document.getElementById('id') — selects by id
  • document.getElementsByClassName('class') — selects by class
  • document.getElementsByTagName('tag') — selects by tag
  • document.querySelector('selector') — first matching element
  • document.querySelectorAll('selector') — all matching elements

DOM — Changing Elements

  • element.textContent = 'text'; — changes text content
  • element.innerHTML = '<p>text</p>'; — changes HTML content
  • element.style.color = '#00ff88'; — changes a CSS style
  • element.style.display = 'none'; — hides an element
  • element.style.display = 'block'; — shows an element
  • element.classList.add('class'); — adds a CSS class
  • element.classList.remove('class'); — removes a CSS class
  • element.classList.toggle('class'); — toggles a CSS class
  • element.getAttribute('attr'); — reads an attribute
  • element.setAttribute('attr', 'value'); — sets an attribute

DOM — Creating Elements

  • document.createElement('tag') — creates a new element
  • element.appendChild(newElement) — adds as last child
  • element.innerHTML = ''; — removes all child elements

Events

  • element.addEventListener('click', function() { }); — click listener
  • element.addEventListener('keypress', function(e) { }); — key listener
  • e.target — the element that triggered the event
  • e.target.tagName — the tag name of the element
  • e.key — the key that was pressed
  • e.preventDefault(); — stops default browser behaviour
  • setTimeout(function() { }, 300); — runs after a delay in ms
