Three Types of List

When thinking about lists in HTML we have 3 types. Let's take a look at each one.

Ordered Lists

An ordered list is where each item in the list is numbered. This is useful for things like steps in a recipe or instructions where the order matters. We need 2 tags — ol to wrap the whole list and li which means list item.

<ol>
  <li>Cut onions into squares</li>
  <li>Add them to the pan with the chicken</li>
  <li>Cook for 10 minutes</li>
</ol>

Unordered Lists

An unordered list usually begins with a bullet point rather than a number. Use this when the order doesn't matter.

<ul>
  <li>Apples</li>
  <li>Oranges</li>
  <li>Pears</li>
</ul>

Definition Lists

A definition list is made up of a set of terms along with the definition for each of those items. Inside the dl element you will often see pairs of dt and dd elements.

  • <dt> — contains the term being defined
  • <dd> — contains the definition
<dl>
  <dt>Tuna pasta bake</dt>
  <dd>Tuna mixed with pasta, cheese and mayo</dd>
</dl>

Nested Lists

You can put a second list inside a li element to create a sub-list or nested list. This is useful when you have items that belong under a main item.

<ul>
  <li>Fruit
    <ul>
      <li>Apples</li>
      <li>Oranges</li>
    </ul>
  </li>
</ul>

🔨 Now Let's Build!

Open your index.html file in Notepad. Add the following code after your existing content inside the body tags:

<h2>My Favourite Things</h2>
<ul>
  <li>Coding</li>
  <li>Late nights</li>
  <li>Learning new things</li>
</ul>

<h2>How to Make Tea</h2>
<ol>
  <li>Boil the kettle</li>
  <li>Add a teabag to your mug</li>
  <li>Pour in the hot water</li>
  <li>Add milk and sugar to taste</li>
</ol>

Save and refresh your browser. You should see a bulleted list and a numbered list appearing on your page!

✅ Your full file should now look like this:

<!DOCTYPE html>
<html>
  <head>
    <title>My First Webpage</title>
  </head>
  <body>
    <h1>Welcome to My Page</h1>
    <p>I am learning to code and this is my first webpage!</p>
    <h2>About Me</h2>
    <p>My name is <strong>[your name]</strong> and I am learning HTML.</p>
    <hr />
    <h2>My Favourite Things</h2>
    <p>I love <em>coding</em> and late nights.</p>
    <p>Did you know water is H<sub>2</sub>O?</p>
    <ul>
      <li>Coding</li>
      <li>Late nights</li>
      <li>Learning new things</li>
    </ul>
    <h2>How to Make Tea</h2>
    <ol>
      <li>Boil the kettle</li>
      <li>Add a teabag to your mug</li>
      <li>Pour in the hot water</li>
      <li>Add milk and sugar to taste</li>
    </ol>
  </body>
</html>

Chapter 3 Quiz

Only move on when you can answer all of these confidently without looking!

1. Which tag is used to create an ordered list?

  • a) <ul>
  • b) <li>
  • c) <ol>
  • d) <list>

2. What does <li> mean?

  • a) Large item
  • b) Line indent
  • c) List item
  • d) Linked item

3. Which type of list would you use for a shopping list where the order doesn't matter?

  • a) Ordered list <ol>
  • b) Definition list <dl>
  • c) Numbered list <nl>
  • d) Unordered list <ul>

4. In a definition list, which tag contains the term being defined?

  • a) <dd>
  • b) <dl>
  • c) <dt>
  • d) <df>
