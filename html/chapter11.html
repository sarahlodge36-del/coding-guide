Colour Can Really Bring Your Pages to Life

The right colour choices set the mood, guide the eye, and make your content easier to read. Get it wrong and your page looks amateurish — or worse, unreadable.

Foreground Colour

The color property sets the colour of the text inside an element. You can specify any colour in CSS in one of three ways.

RGB values express a colour as a mix of red, green, and blue. Each value sits between 0 and 255.

p { color: rgb(100,100,90); }

Hex codes are six-digit codes representing the same red, green, and blue values, but written in hexadecimal. They're preceded by a # symbol.

h2 { color: #ee3e80; }

Colour names — there are 147 predefined colour names that browsers recognise. They're fine for quick testing but limited, and nobody's memorising 147 names.

h1 { color: DarkCyan; }

You can also add comments to your CSS files using /* */. Anything between those symbols is ignored by the browser — useful for labelling sections of a long stylesheet.

/* this is a comment */
h1 { color: DarkCyan; }

Background Colour

CSS treats every HTML element as if it sits inside a box, and background-color sets the colour of that box. You specify it the same three ways — RGB, hex, or colour name.

body { background-color: rgb(200,200,200); }
h1  { background-color: DarkCyan; }
h2  { background-color: #ee3e80; }
p   { background-color: white; }

If you don't set a background colour, it defaults to transparent — which usually means the browser's default white shows through, but don't rely on that since users can change their browser's default background. If you want white, set it explicitly.

Understanding Colour

Every colour on a computer screen is created by mixing amounts of red, green, and blue — just like a television screen. Monitors are made up of thousands of tiny squares called pixels, and when the screen is off it's black because no light is being emitted. When it's on, each pixel can be a different colour, and those pixels together create the image you see.

To find the colour you want, use a colour picker — image editing tools like Photoshop and GIMP have them built in, and there are free ones online too. The colour picker will show you the RGB values and the hex code for whatever colour you land on.

Hue, Saturation and Brightness

These are terms you'll come across when working with colour.

Hue is closest to the everyday idea of colour — red, blue, green and so on.

Saturation is the amount of grey in a colour. At maximum saturation there's no grey at all. At minimum saturation the colour is mostly grey.

Brightness refers to how much black is in a colour. Maximum brightness means no black; minimum brightness means the colour is very dark.

Contrast

When picking your foreground and background colours, contrast matters. Low contrast makes text hard to read — and it's a real problem for anyone with a visual impairment or colour blindness, or anyone using their phone in daylight.

High contrast makes text easy to read, but too much contrast for long stretches of text can actually make it harder on the eyes too. For bodies of text, a medium contrast — dark grey on white, or off-white on dark — tends to work better than pure black on pure white.

If you're using light text on a dark background, consider increasing the line height and font weight slightly to help with readability.

Opacity and RGBA

CSS3 introduced the opacity property, which lets you make an element (and all its children) semi-transparent. The value is a number between 0.0 and 1.0 — so 0.5 is 50% opacity and 0.15 is 15%.

p { background-color: rgb(0,0,0); opacity: 0.5; }

rgba works like rgb but adds a fourth value — the alpha — to control opacity. Unlike opacity, it only affects the element itself, not its children.

p { background-color: rgba(0,0,0,0.5); }

Because older browsers may not support rgba, it's good practice to write a fallback first using a plain RGB or hex value. The browser will use the rgba rule if it understands it, and fall back to the solid colour if not.

HSL and HSLA

CSS3 also introduced a new way to specify colours using hue, saturation, and lightness — HSL.

Hue is expressed as an angle between 0 and 360 degrees (think of a colour wheel). Saturation is a percentage — 100% is full colour, 0% is grey. Lightness is also a percentage — 0% is black, 100% is white, and 50% is normal.

body { background-color: hsl(0, 0%, 78%); }

HSLA adds a fourth value for transparency (alpha), just like rgba.

p { background-color: hsla(0, 100%, 100%, 0.5); }

Because older browsers don't support HSL and HSLA, write a fallback hex or RGB value before the HSL rule so those browsers still get something sensible.

🔨 Now Let's Build!

Open your styles.css file in Notepad. We're going to give your page some actual colour. Add this to your stylesheet:

body {
  font-family: Arial, sans-serif;
  background-color: #1a1a1a;
  color: #f0f0f0;
}

h1 {
  color: #ee3e80;
}

h2 {
  color: #00d4ff;
}

Save and refresh your browser. Your page should now have a dark background with light text, a pink h1 heading, and blue h2 headings. Notice the contrast — light text on a dark background is easy on the eye when done properly!
