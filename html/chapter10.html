What is CSS?

CSS stands for Cascading Style Sheets. While HTML gives your page its structure and content, CSS is what makes it look good. It lets you control colours, fonts, sizes, spacing and layouts — basically everything to do with how your page appears.

The key to understanding how CSS works is to imagine that there is an invisible box around every HTML element. CSS lets you create rules that control how each of those boxes — and the content inside them — is displayed.

CSS Rules

A CSS rule has two parts: a selector and a declaration.

p {
  font-family: Arial;
}

The selector (p) tells the browser which element the rule applies to. The declaration (font-family: Arial;) tells the browser how to style it.

You can apply the same rule to more than one element by separating the element names with commas:

h1, h2, h3 {
  font-family: Arial;
  color: yellow;
}

Properties and Values

Each declaration is made up of two parts: a property and a value, separated by a colon. Multiple declarations are separated by semicolons and all sit inside curly brackets.

The property is the aspect of the element you want to change — for example color, font-family, width, or border. The value is the setting you want to apply to that property — for example red, Arial, 400px.

h1, h2 {
  font-family: Arial;
  color: yellow;
}

This rule tells the browser to display all h1 and h2 elements in Arial, in yellow.

Thinking Inside the Box

The key to understanding CSS is remembering that every HTML element lives inside its own invisible box. Block level elements like h1, p, ul and div each start on a new line and take up their own box. Inline elements like a, b, em and img flow within the text and sit inside a smaller box within the line.

CSS lets you control both the box itself (its size, border, background colour) and the content inside it (its font, colour, text size).

Using External CSS

The best way to add CSS to your pages is to keep it in a separate file with a .css extension and link to it from your HTML. This is called an external stylesheet.

You link to it using the link element inside the head of your HTML page:

<!DOCTYPE html>
<html>
  <head>
    <title>My Page</title>
    <link href="css/styles.css" type="text/css" rel="stylesheet" />
  </head>
  <body>
    <h1>Potatoes</h1>
  </body>
</html>
  • href — the path to your CSS file
  • type — the type of document being linked. For CSS this is always text/css
  • rel — the relationship between the HTML page and the linked file. For a CSS file this is always stylesheet

Using Internal CSS

You can also write CSS rules directly inside your HTML page using the style element, which sits inside the head. This is called internal CSS.

<head>
  <style type="text/css">
    body { font-family: arial; }
    h1 { color: white; }
  </style>
</head>

Internal CSS is fine for a single page, but if your site has more than one page you should always use an external stylesheet — that way one change updates every page at once.

CSS Selectors

There are several types of CSS selector that let you target different elements in different ways.

  • Universal selector — targets every element on the page: * { font-family: Arial; }
  • Type selector — targets all elements of a specific type: h1, h2, h3 { color: blue; }
  • Class selector — targets any element with a matching class attribute, using a dot before the class name: .note { color: grey; }
  • ID selector — targets the element with a matching id attribute, using a hash before the id name: #introduction { font-size: 120%; }

CSS selectors are case sensitive, so they must match your HTML exactly.

How CSS Rules Cascade

CSS stands for Cascading Style Sheets — and the cascading part is important. When two or more rules apply to the same element, the browser needs to decide which one wins.

  • Last rule — if two selectors are identical, the one that appears last in the stylesheet takes precedence
  • Specificity — if one selector is more specific than another, the more specific rule wins
  • Important — you can add !important after a property value to force it to take priority over other rules

Understanding the cascade means you can write simpler stylesheets — set general rules for most elements and then override just the ones that need to look different.

Inheritance

Some CSS properties are passed down from parent elements to their children — this is called inheritance. For example if you set font-family on the body element, most elements inside the body will inherit that font automatically.

Not everything is inherited though. Properties like background-color and border are not inherited — and that's a good thing, otherwise every element inside a styled div would end up with the same border and background!

🔨 Now Let's Build!

This is the big moment. Open your index.html file in Notepad. We're going to link it to a brand new CSS file for the first time.

First, create a new folder next to your index.html file called css. Inside that folder, create a new file in Notepad and save it as styles.css (choose All Files when saving).

Now go back to your index.html file and add this line inside your head tags, just before the closing </head>:

<link href="css/styles.css" type="text/css" rel="stylesheet" />

Now open your new styles.css file and add this:

body {
  font-family: Arial, sans-serif;
  background-color: #f0f0f0;
}

h1 {
  color: #ee3e80;
}

Save both files and refresh your browser. Your page should now have a light grey background, a new font, and your h1 heading should be pink!
