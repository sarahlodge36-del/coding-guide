CSS

Advanced Cheat Sheet

Modern CSS is powerful. Keep this reference close. 😎

Flexbox

  • display: flex; — turns element into a flex container
  • flex-direction: row; — arranges children horizontally (default)
  • flex-direction: column; — arranges children vertically
  • flex-wrap: wrap; — allows children to wrap onto multiple lines
  • justify-content: flex-start; — aligns children to the start
  • justify-content: flex-end; — aligns children to the end
  • justify-content: center; — centres children
  • justify-content: space-between; — equal space between children
  • justify-content: space-around; — equal space around children
  • align-items: flex-start; — aligns children to top of cross axis
  • align-items: flex-end; — aligns children to bottom of cross axis
  • align-items: center; — centres children on cross axis
  • align-items: stretch; — stretches children to fill container (default)
  • gap: 20px; — space between flex children
  • flex: 1; — on a child, makes it grow to fill available space
  • flex: 0 0 200px; — fixed width child that won't grow or shrink
  • order: 2; — changes the visual order of a flex child
  • align-self: center; — overrides align-items for a single child

CSS Grid

  • display: grid; — turns element into a grid container
  • grid-template-columns: 1fr 1fr 1fr; — three equal columns
  • grid-template-columns: repeat(3, 1fr); — same as above, shorthand
  • grid-template-columns: 200px 1fr 1fr; — fixed and fluid columns
  • grid-template-rows: auto; — rows size to content
  • grid-template-rows: 100px 1fr auto; — mixed row sizes
  • gap: 20px; — space between grid cells
  • column-gap: 20px; — space between columns only
  • row-gap: 20px; — space between rows only
  • grid-column: 1 / 3; — item spans from column line 1 to 3
  • grid-column: span 2; — item spans 2 columns
  • grid-row: 1 / 3; — item spans from row line 1 to 3
  • grid-area: header; — assigns item to a named area
  • grid-template-areas: "header header" "sidebar content"; — named layout
  • justify-items: center; — aligns all items horizontally within cells
  • align-items: center; — aligns all items vertically within cells
  • minmax(200px, 1fr) — column minimum and maximum size
  • auto-fill — fills row with as many columns as will fit
  • auto-fit — same as auto-fill but collapses empty tracks

Media Queries

  • @media (min-width: 768px) { } — applies from 768px and above
  • @media (max-width: 767px) { } — applies up to 767px
  • @media (min-width: 768px) and (max-width: 1024px) { } — range
  • @media (orientation: landscape) { } — landscape orientation
  • @media (prefers-color-scheme: dark) { } — dark mode preference
  • @media (prefers-reduced-motion: reduce) { } — reduced motion preference
  • @media print { } — print styles

Common breakpoints: 480px (mobile), 768px (tablet), 1024px (desktop), 1200px (wide)

CSS Custom Properties — Variables

  • :root { --primary: #ff2d78; } — declares a global variable
  • color: var(--primary); — uses a variable
  • color: var(--primary, #ff0000); — uses variable with fallback
  • --spacing: 20px; — variables can store any CSS value
  • element.style.setProperty('--primary', '#00ff88'); — JavaScript can change variables

Transitions

  • transition: color 0.3s ease; — transitions one property
  • transition: all 0.3s ease; — transitions all changing properties
  • transition: color 0.3s ease, background 0.5s linear; — multiple transitions
  • transition-duration: 0.3s; — how long the transition takes
  • transition-timing-function: ease; — ease, linear, ease-in, ease-out, ease-in-out
  • transition-delay: 0.2s; — wait before starting
  • cubic-bezier(0.4, 0, 0.2, 1) — custom timing curve

Animations

  • @keyframes name { 0% { } 100% { } } — defines an animation
  • @keyframes name { from { } to { } } — shorthand for 0% and 100%
  • animation: name 2s ease infinite; — shorthand animation property
  • animation-name: pulse; — which keyframe to use
  • animation-duration: 2s; — how long one cycle takes
  • animation-timing-function: ease; — timing curve
  • animation-iteration-count: infinite; — loops forever
  • animation-iteration-count: 3; — runs 3 times
  • animation-delay: 0.5s; — wait before starting
  • animation-direction: alternate; — reverses on even cycles
  • animation-fill-mode: forwards; — keeps final state after finishing
  • animation-play-state: paused; — pauses the animation

Pseudo-Elements

  • ::before — inserts content before the element's content
  • ::after — inserts content after the element's content
  • content: ''; — required on pseudo-elements even if empty
  • content: '⚡'; — inserts text or emoji
  • content: attr(data-label); — inserts the value of an attribute
  • ::first-line — targets the first line of text
  • ::first-letter — targets the first letter
  • ::placeholder — styles input placeholder text
  • ::selection — styles highlighted/selected text

Advanced Selectors

  • p:first-child — p that is the first child of its parent
  • p:last-child — p that is the last child
  • p:nth-child(2) — the second child
  • p:nth-child(odd) — odd numbered children
  • p:nth-child(even) — even numbered children
  • p:nth-child(3n) — every third child
  • p:not(.special) — p elements without the class special
  • input:checked — checked checkboxes and radio buttons
  • input:disabled — disabled inputs
  • input:valid — inputs passing validation
  • input:invalid — inputs failing validation
  • p + p — adjacent sibling selector
  • p ~ p — general sibling selector
  • div > p — direct child selector
  • [data-mode="question"] — attribute selector
  • [class^="btn"] — class starting with btn
  • [class*="icon"] — class containing icon

Useful Functions

  • calc(100% - 300px) — calculates values mixing units
  • clamp(1rem, 5vw, 3rem) — fluid value between min and max
  • min(500px, 100%) — uses the smaller of two values
  • max(300px, 50%) — uses the larger of two values
  • var(--name) — uses a CSS custom property
  • rgb(255, 0, 0) — RGB colour
  • rgba(255, 0, 0, 0.5) — RGB with transparency
  • hsl(0, 100%, 50%) — HSL colour
  • linear-gradient(135deg, #ff2d78, #00d4ff) — gradient
  • radial-gradient(circle, #ff2d78, #0a0a0a) — radial gradient

Transform

  • transform: translateX(20px); — moves element horizontally
  • transform: translateY(20px); — moves element vertically
  • transform: translate(20px, 20px); — moves both axes
  • transform: scale(1.1); — scales element up by 10%
  • transform: rotate(45deg); — rotates element
  • transform: skew(10deg); — skews element
  • transform: scale(1.1) rotate(45deg); — multiple transforms
  • transform-origin: center; — point around which transform occurs

Filters

  • filter: blur(5px); — blurs element
  • filter: brightness(0.8); — darkens element
  • filter: contrast(1.2); — increases contrast
  • filter: grayscale(100%); — removes colour
  • filter: opacity(0.5); — makes element semi-transparent
  • filter: drop-shadow(2px 2px 5px #000); — shadow following shape
  • backdrop-filter: blur(10px); — blurs content behind element
