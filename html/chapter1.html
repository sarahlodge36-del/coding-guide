What is HTML?

HTML stands for Hypertext Markup Language. It is the language used to build webpages.

HTML uses tags — characters that sit inside angled brackets — to give the information they surround special meaning. Tags are often referred to as elements.

HTML Elements

Elements are characters that live inside angled brackets — these are called opening and closing tags. Each element tells the browser something about the information that sits between the opening and closing tag.

<body> hi </body>

Tags act like containers. Here are some of the most common ones:

  • <html> — tells the browser this is HTML code
  • <body> — content shown inside the main browser window
  • <h1> — main heading
  • <h2> — subheading
  • <p> — paragraph

Body, Head and Title

The body element is shown inside the main browser window. The <head> element sits before the body and contains info about the page. Inside the head you will usually find a <title> tag — this appears at the top of the browser, above where you type the URL.

Closing Tags

Every opening tag needs a closing tag. The closing tag has a forward slash before the element name.

</html> </body> </h1> </p>

Attributes

Attributes provide additional info about the contents of an element. They appear on the opening tag and are made up of two parts — a name and a value, separated by an equals sign.

<p lang="en-us"> text here </p>

The attribute name is lang and the value is en-us — meaning US English. The value always sits inside quotation marks.

Fun Fact

The Hypertext part of HTML refers to the fact that HTML allows you to create links that let users move to another page. The Markup Language part means it allows you to annotate text — and those annotations give the contents of a document additional meaning.

Creating a Webpage on a PC

Open Notepad (Start → All Programs → Accessories → Notepad). Type your code, then save as firstpage.html choosing All Files. Open it in your browser and it will open as a webpage.

Peek Behind Any Website

Right-click on any webpage and select View Page Source (or press Ctrl+U). You'll see the actual HTML that built that page. Don't panic if it looks overwhelming — by the end of this guide it will make sense.

🔨 Now Let's Build!

⚡ Before We Start — Something Important!

When building your webpage you will be using two different programs — and it's really important to understand the difference:

  • Notepad — this is where you write and edit your code. Think of it as your workbench.
  • Your Browser (Chrome, Edge, Firefox etc) — this is where you see the result. Think of it as your preview window.

They are both looking at the same file — but doing completely different things with it. Notepad reads it as text. Your browser reads it as a webpage.

The workflow is simple:

  • 1. Open your file in Notepad to write or change your code
  • 2. Save the file in Notepad (Ctrl+S)
  • 3. Open or refresh your browser (F5 or Ctrl+R) to see the changes

That's it! Save in Notepad, refresh in browser. You'll be doing this hundreds of times so it'll become second nature very quickly 😄

Not keen on Notepad? There's another option — CodePen (codepen.io). It's a free website where you type your HTML, CSS, and JavaScript and see the result update live, instantly, with no saving or refreshing required. Either tool works perfectly fine for this guide — pick whichever one feels more comfortable to you. Just know that later on, when we reach the JavaScript section, we'll be using CodePen — so if you start there now, you'll already feel right at home.

One more thing — if you ever get properly stuck and want to talk something through rather than just look up an answer, I personally use Claude (the AI assistant) when I want to actually understand something rather than just copy it. It's not a requirement for this guide and there's no pressure to use it — just sharing what works for me. 😄

Open Notepad on your PC and type out the following code. Don't copy and paste — type it out. Your fingers need to learn this too!

Save the file as index.html — remember to choose All Files when saving in Notepad. This is the file we will be adding to all the way through the guide so keep it safe!

<!DOCTYPE html>
<html>
  <head>
    <title>My First Webpage</title>
  </head>
  <body>
    <h1>Welcome to My Page</h1>
    <p>I am learning to code and this is my first webpage!</p>
  </body>
</html>

Now open your browser and drag your index.html file into it — or right click the file and choose Open With and select your browser. You should see your webpage appear!

file:///C:/Users/Home/index.html

Welcome to My Page

I am learning to code and this is my first webpage!
