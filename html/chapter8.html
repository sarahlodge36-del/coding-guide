HTML Cheat Sheet

Eight chapters in. Nearly at the end of HTML. Don't drop the ball now — quiz first. 👀

A Bit of History

Since the web was first created there have been several versions of HTML. Each new version was designed to be an improvement on the last.

  • HTML 4 (1997) — contained most of the elements you've seen in this guide
  • XHTML 1.0 (2000) — a stricter version that followed XML rules. Every element needed a closing tag and attribute values had to sit inside quotation marks
  • HTML5 — the version we use today. Still evolving and widely supported

Doctypes

Because there have been several versions of HTML, each web page should start with a DOCTYPE declaration. This tells the browser which version of HTML the page is using. For HTML5 the doctype is nice and simple:

<!DOCTYPE html>

You'll see this at the very top of every modern HTML page — including the ones you've been building!

Comments in HTML

You can add comments to your HTML that won't show up in the browser. This is really useful for leaving notes for yourself explaining what different sections do. Remember those <!-- --> things you might have noticed in code examples? That's what they are!

<!-- This is a comment -->

<!-- start of main content -->
<h1>Welcome</h1>
<!-- end of main content -->

Block Elements

Some elements always start on a new line in the browser. These are called block level elements. Examples include h1, p, ul, and li.

<h1>Coding Guide</h1>
<p>Welcome to chapter 8.</p>
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

Inline Elements

Inline elements continue on the same line as their neighbouring elements rather than starting on a new line. Examples include a, b, em, and img.

<p>I love <b>coding</b> and <em>late nights</em>.</p>

Grouping Elements — div and span

The div element lets you group a set of elements together into one block-level box. On its own it doesn't change how things look, but it becomes really powerful when you add CSS.

span is the inline equivalent of div. It lets you wrap a section of text so you can style it with CSS later. On its own span does nothing — its purpose is to give you a hook to apply styles to specific inline content.

<div id="header">
  <h1>My Site</h1>
</div>

<p>Studied at <span class="school">Milton Keynes College</span></p>

Escape Characters

Some characters are reserved by HTML — the angled brackets are a good example, since the browser would try to read them as tags. To display these characters on your page you need to use escape codes. You've actually already seen these in the code examples throughout this guide — now you know what they are!

  • &lt; — displays <
  • &gt; — displays >
  • &amp; — displays &
  • &copy; — displays ©
  • &nbsp; — adds a non-breaking space
<p>The &lt;p&gt; tag creates a paragraph.</p>

Semantic HTML5 Elements

So far we've used div to group sections of our page — and that works perfectly well. But HTML5 introduced some extra elements that do the same job as div while also telling the browser (and screen readers) what kind of content is inside them. These are called semantic elements.

  • <header> — used for introductory content, usually at the top of a page
  • <nav> — used to wrap navigation links
  • <main> — used for the main unique content of the page
  • <section> — used to group related content together
  • <article> — used for self-contained content like a blog post
  • <footer> — used for closing content, usually at the bottom of a page

You don't have to use these instead of div — div still works fine and you'll see plenty of real websites that mix both. But using semantic elements where it makes sense is considered best practice, because it gives extra meaning to your page without changing how anything looks.

<header>
  <h1>My Site</h1>
  <nav><a href="#">Home</a></nav>
</header>

<footer>
  <p>&copy; My Site 2024</p>
</footer>

🔨 Now Let's Build!

Open your index.html file in Notepad. We're going to tidy it up and add some structure using div elements and comments. Wrap your existing content in divs like this:

<!-- start header -->
<div id="header">
  <h1 id="top">Welcome to My Page</h1>
  <p>I am learning to code and this is my first webpage!</p>
</div>
<!-- end header -->

<!-- start content -->
<div id="content">
  <!-- all your existing content goes here -->
</div>
<!-- end content -->

<!-- start footer -->
<div id="footer">
  <p>&copy; My First Webpage 2024</p>
</div>
<!-- end footer -->

Save and refresh. The page won't look different yet but the structure is much cleaner — and that matters when CSS arrives! 🚀

file:///C:/Users/Home/index.html

Your page will look the same as before — the div elements and comments are invisible in the browser. But your code is now much better structured and ready for CSS!

© My First Webpage 2024

👆 The divs are invisible but your footer copyright notice should appear at the bottom!

✅ Your full file should now look like this:

<!DOCTYPE html>
<html>
  <head>
    <title>My First Webpage</title>
  </head>
  <body>
    <!-- start header -->
    <div id="header">
      <h1 id="top">Welcome to My Page</h1>
      <p>I am learning to code and this is my first webpage!</p>
    </div>
    <!-- end header -->
    <!-- start content -->
    <div id="content">
      <h2>About Me</h2>
      <p>My name is <strong>[your name]</strong> and I am learning HTML.</p>
      <hr />
      <h2>My Favourite Things</h2>
      <p>I love <em>coding</em> and late nights.</p>
      <p>Did you know water is H<sub>2</sub>O?</p>
      <ul>
        <li>Coding</li>
        <li>Late nights</li>
        <li>Learning new things</li>
      </ul>
      <h2>How to Make Tea</h2>
      <ol>
        <li>Boil the kettle</li>
        <li>Add a teabag to your mug</li>
        <li>Pour in the hot water</li>
        <li>Add milk and sugar to taste</li>
      </ol>
      <h2>Useful Links</h2>
      <p><a href="http://www.w3schools.com">W3Schools</a> — free HTML tutorials</p>
      <p><a href="http://www.freecodecamp.org">freeCodeCamp</a> — free coding challenges</p>
      <p><a href="mailto:your@email.com">Contact Me</a></p>
      <p><a href="#top">Back to top</a></p>
      <h2>A Photo I Like</h2>
      <img src="images/myphoto.jpg" alt="A photo I chose" width="400" height="300" />
      <h2>My Weekly Schedule</h2>
      <table>
        <tr><th>Day</th><th>Activity</th></tr>
        <tr><td>Monday</td><td>HTML</td></tr>
        <tr><td>Tuesday</td><td>CSS</td></tr>
        <tr><td>Wednesday</td><td>JavaScript</td></tr>
      </table>
      <h2>Contact Me</h2>
      <form action="mailto:your@email.com" method="get">
        <fieldset>
          <legend>Your Details</legend>
          <label>Name:<br /><input type="text" name="name" /></label><br />
          <label>Email:<br /><input type="text" name="email" /></label><br />
          <label>Message:<br /><textarea name="message"></textarea></label><br />
          <input type="submit" value="Send Message" />
        </fieldset>
      </form>
    </div>
    <!-- end content -->
    <!-- start footer -->
    <div id="footer">
      <p>&copy; My First Webpage 2024</p>
    </div>
    <!-- end footer -->
  </body>
</html>
