ES6 and Beyond

The JavaScript you learned in Chapters 20 to 25 is solid, foundational JavaScript. But the language has evolved significantly since then. ES6 — also known as ECMAScript 2015 — introduced a wave of new features that made JavaScript cleaner, more expressive, and more powerful. Almost everything you'll read in modern JavaScript tutorials and job descriptions uses these features.

This page is an overview of what's waiting beyond the basics. These are the features you'll encounter in the wild and study in depth in the paid section of this guide.

Arrow Functions

Arrow functions are a shorter, cleaner way to write functions. Instead of the function keyword you use an arrow =>.

// Traditional function
function greet(name) {
  return 'Hello ' + name;
}

// Arrow function — same thing
const greet = (name) => {
  return 'Hello ' + name;
};

// Even shorter — implicit return for single expressions
const greet = name => 'Hello ' + name;

Arrow functions are everywhere in modern JavaScript. They're especially common as callback functions passed into array methods and event listeners.

Template Literals

Template literals are a better way to build strings. Instead of concatenating with + you use backticks and embed expressions directly inside the string using ${}.

// Old way — concatenation
var message = 'Welcome, ' + playerName + '. Lives: ' + playerHealth;

// New way — template literal
const message = `Welcome, ${playerName}. Lives: ${playerHealth}`;

// Can span multiple lines
const html = `
  <div class="card">
    <h2>${title}</h2>
    <p>${description}</p>
  </div>
`;

Template literals make string building dramatically cleaner. Once you use them you'll never want to go back to concatenation.

Destructuring

Destructuring lets you unpack values from arrays or objects into individual variables in a single clean statement.

// Array destructuring
const [first, second, third] = ['HTML', 'CSS', 'JavaScript'];
console.log(first); // 'HTML'
console.log(second); // 'CSS'

// Object destructuring
const player = { name: 'Sarah', health: 3, score: 100 };
const { name, health, score } = player;
console.log(name); // 'Sarah'
console.log(health); // 3

Destructuring is particularly useful when working with data from APIs — you'll often destructure the response object to pull out just the properties you need.

Spread and Rest Operators

The spread operator (...) expands an array or object into individual elements. The rest operator uses the same syntax but collects multiple elements into an array.

// Spread — expanding an array
const htmlItems = ['h1', 'p', 'div'];
const cssItems = ['color', 'margin'];
const allItems = [...htmlItems, ...cssItems];

// Spread — copying an object
const player = { name: 'Sarah', health: 3 };
const updatedPlayer = { ...player, health: 2 };

// Rest — collecting remaining arguments
function logAll(first, ...rest) {
  console.log(first);
  console.log(rest);
}

Array Methods — map, filter, reduce

These three array methods are some of the most powerful and commonly used tools in modern JavaScript. They replace many use cases for traditional for loops.

const scores = [100, 200, 50, 300, 75];

// map — transforms every item and returns a new array
const doubled = scores.map(score => score * 2);

// filter — returns only items that pass a test
const highScores = scores.filter(score => score >= 100);

// reduce — combines all items into a single value
const total = scores.reduce((sum, score) => sum + score, 0);

The Fetch API and Promises

The Fetch API is how JavaScript retrieves data from external sources — APIs, databases, other servers — without reloading the page. It returns a Promise — an object representing a value that will be available in the future.

fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => {
    console.log(data);
  })
  .catch(error => {
    console.log('Something went wrong:', error);
  });

async / await

async/await is a cleaner way to work with Promises. Instead of chaining .then() you can write asynchronous code that reads like regular synchronous code.

async function getData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.log('Something went wrong:', error);
  }
}

getData();

Error Handling — try / catch

The try/catch statement lets you handle errors gracefully rather than letting them crash your script.

try {
  var result = JSON.parse(someData);
  console.log(result);
} catch (error) {
  console.log('Failed to parse data:', error.message);
} finally {
  console.log('Done.');
}

localStorage

localStorage lets you store data in the browser that persists even after the page is closed and reopened.

localStorage.setItem('playerName', 'Sarah');
var name = localStorage.getItem('playerName');
localStorage.removeItem('playerName');
localStorage.clear();

// Storing objects
localStorage.setItem('player', JSON.stringify(player));
var saved = JSON.parse(localStorage.getItem('player'));

JavaScript Modules

As your JavaScript grows it becomes important to split it into separate files — modules. Each module exports the functions and variables it wants to share, and other modules import what they need.

// game.js — exporting
export function startGame() { ... }
export const gameName = 'The Code Machine Quest';

// main.js — importing
import { startGame, gameName } from './game.js';
startGame();
