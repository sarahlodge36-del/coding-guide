Finer Control Over Specific Elements

There are several CSS properties that were created to work with specific types of HTML elements, such as lists, tables, and forms. In this chapter we look at how to take finer control over each of these.

Bullet Point Styles — list-style-type

The list-style-type property lets you control the shape or style of the bullet point on unordered lists, and the numbering style on ordered lists.

ul { list-style-type: none; }
ul { list-style-type: disc; }
ul { list-style-type: square; }
ol { list-style-type: decimal; }
ol { list-style-type: lower-alpha; }
ol { list-style-type: upper-roman; }

Positioning the Marker — list-style-position

By default the bullet or number sits outside the main flow of text. You can bring it inside using list-style-position.

ul { list-style-position: outside; }
ul { list-style-position: inside; }

Table Proportions — width, padding

Setting a width on the table and padding on the cells gives the table more breathing room and makes it easier to read.

table { width: 600px; }
th, td { padding: 10px; }

Gaps Between Cells — border-collapse

By default browsers leave a small gap between table cells. If you'd rather have no gap at all — so borders between adjacent cells merge into one — use border-collapse.

table { border-collapse: collapse; }

Styling Forms

Forms are notoriously tricky to style because different browsers render form controls differently. CSS gives you some control but it's rarely perfect across every browser. The key is to focus on making forms clear and easy to use.

Styling Text Inputs

input {
  font-size: 100%;
  background-color: #f2f2f2;
  border: 1px solid #bdbdbd;
  border-radius: 5px;
  padding: 8px;
}

input:focus {
  background-color: #ffffff;
  border: 1px solid #00d4ff;
}

The :focus pseudo-class lets you change the appearance of the input when the user clicks into it — a nice touch that helps users see which field they're in.

Styling Submit Buttons

input[type="submit"] {
  background-color: #ee3e80;
  color: #ffffff;
  padding: 10px 20px;
  border: none;
  border-radius: 5px;
  cursor: pointer;
}

Using the attribute selector input[type="submit"] means these styles only target the submit button and not every input on the page.

Cursor Styles — cursor

The cursor property lets you control what the mouse pointer looks like when it hovers over an element.

a       { cursor: pointer; }
input   { cursor: text; }
div     { cursor: move; }

🔨 Now Let's Build!

Open your styles.css file in Notepad. We're going to style your list, table, and form properly. Add this to your stylesheet:

ul {
  list-style-type: square;
}

table {
  border-collapse: collapse;
  width: 100%;
}

th, td {
  padding: 10px;
  border: 1px solid #444444;
  text-align: left;
}

th {
  background-color: #ee3e80;
  color: #ffffff;
}

input, textarea {
  background-color: #2a2a2a;
  border: 1px solid #444444;
  border-radius: 5px;
  padding: 8px;
  color: #f0f0f0;
}

input[type="submit"] {
  background-color: #ee3e80;
  color: #ffffff;
  border: none;
  padding: 10px 20px;
  cursor: pointer;
}

Save and refresh your browser. Your table now has a pink header row with proper borders, your form fields have a dark styled background that matches your page, and your submit button looks like an actual clickable button!

Chapter 14 Quiz

Only move on when you can answer all of these confidently without looking!

1. Which CSS property controls the style of bullet points on an unordered list?

  • a) list-style-image
  • b) list-style-position
  • c) list-style-type
  • d) bullet-style

2. What does border-collapse: collapse do on a table?

  • a) Removes all borders from the table
  • b) Merges adjacent cell borders so there is no gap between them
  • c) Hides empty cells
  • d) Makes the table collapse to zero height

3. Why is it better to use input[type="submit"] rather than just input when styling a submit button?

  • a) It makes the button look better
  • b) It targets only the submit button without affecting every other input on the page
  • c) It is the only way to style a submit button
  • d) It works in older browsers

4. Which pseudo-class would you use to change the appearance of a text input when the user clicks into it?

  • a) :hover
  • b) :active
  • c) :visited
  • d) :focus

5. What does the cursor property do?

  • a) Controls the size of the mouse pointer
  • b) Controls what the mouse pointer looks like when hovering over an element
  • c) Makes an element clickable
  • d) Changes the colour of the mouse pointer
