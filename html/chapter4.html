What are Links?

Links allow us to move from one page to another. They are what makes the web a web! There are 5 common types of link:

  • Links from one website to another
  • Links from one page of a website to another page within that website
  • Links from one part of a web page to another part of that same page
  • Links that open a new browser window
  • Links that start up your email program and address a new email to someone

Writing Links

We create links using the a tag and we use the href attribute to specify which page we want to link to. The text between the opening and closing a tags is known as the link text.

<a href="http://www.pencils.com">Pencils</a>

Linking to Other Sites

When linking to a website the href value will take you to that website. This is known as an absolute URL — the full web address that starts with the domain name.

<a href="http://www.google.com">Google</a>

Linking to Other Pages on the Same Site

When linking to pages within the same site you can use a relative URL — a shorthand version that just uses the file name. You don't need the full web address, just the name of the file.

<a href="about.html">About</a>

Email Links

To create a link that opens the user's email program with a new message addressed to someone, use mailto: followed by the email address.

<a href="mailto:sarah@example.org">Email Sarah</a>

Opening Links in a New Window

If you want a link to open in a new browser window, use the target attribute with a value of _blank.

<a href="http://www.imdb.com" target="_blank">IMDB</a>

Linking to a Specific Part of the Same Page

Use the id attribute to identify specific points on the page, then link to them using # followed by the id value. This is great for long pages where you want a "back to top" button.

<h1 id="top">Page Title</h1>
<a href="#top">Back to top</a>

🔨 Now Let's Build!

Open your index.html file in Notepad. We're going to add some links to it. Add this after your existing content inside the body tags:

<h2>Useful Links</h2>
<p><a href="http://www.w3schools.com">W3Schools</a> — free HTML tutorials</p>
<p><a href="http://www.freecodecamp.org">freeCodeCamp</a> — free coding challenges</p>
<p><a href="mailto:your@email.com">Contact Me</a></p>
<p><a href="#top">Back to top</a></p>

Don't forget to add id="top" to your h1 tag at the top of the page so the back to top link works!

<h1 id="top">Welcome to My Page</h1>

Save and refresh your browser. Click the links and see what happens! 🚀

✅ Your full file should now look like this:

<!DOCTYPE html>
<html>
  <head>
    <title>My First Webpage</title>
  </head>
  <body>
    <h1 id="top">Welcome to My Page</h1>
    <p>I am learning to code and this is my first webpage!</p>
    <h2>About Me</h2>
    <p>My name is <strong>[your name]</strong> and I am learning HTML.</p>
    <hr />
    <h2>My Favourite Things</h2>
    <p>I love <em>coding</em> and late nights.</p>
    <p>Did you know water is H<sub>2</sub>O?</p>
    <ul>
      <li>Coding</li>
      <li>Late nights</li>
      <li>Learning new things</li>
    </ul>
    <h2>How to Make Tea</h2>
    <ol>
      <li>Boil the kettle</li>
      <li>Add a teabag to your mug</li>
      <li>Pour in the hot water</li>
      <li>Add milk and sugar to taste</li>
    </ol>
    <h2>Useful Links</h2>
    <p><a href="http://www.w3schools.com">W3Schools</a> — free HTML tutorials</p>
    <p><a href="http://www.freecodecamp.org">freeCodeCamp</a> — free coding challenges</p>
    <p><a href="mailto:your@email.com">Contact Me</a></p>
    <p><a href="#top">Back to top</a></p>
  </body>
</html>
