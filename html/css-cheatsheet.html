CSS Basics

  • selector { property: value; } — the basic structure of a CSS rule
  • /* comment */ — CSS comment, ignored by the browser
  • <link rel="stylesheet" href="css/styles.css" /> — links an external CSS file
  • <style> ... </style> — internal CSS in the head of the HTML file

Selectors

  • * — universal selector, targets every element
  • p — type selector, targets all p elements
  • .classname — class selector, targets elements with that class
  • #idname — id selector, targets the element with that id
  • h1, h2, h3 — targets multiple elements at once
  • p a — descendant selector, targets a elements inside p elements

Colour

  • color: #ee3e80; — sets text colour using hex
  • color: rgb(255, 0, 0); — sets text colour using RGB
  • color: red; — sets text colour using a colour name
  • background-color: #1a1a1a; — sets background colour
  • opacity: 0.5; — makes element and children semi-transparent
  • background-color: rgba(0,0,0,0.5); — semi-transparent background only
  • color: hsl(0, 100%, 50%); — colour using hue, saturation, lightness
  • color: hsla(0, 100%, 50%, 0.5); — HSL with transparency

Text

  • font-family: Arial, sans-serif; — sets typeface with fallback stack
  • font-size: 16px; — sets font size in pixels
  • font-size: 1.2em; — sets font size relative to parent
  • font-weight: bold; — makes text bold
  • font-style: italic; — makes text italic
  • text-transform: uppercase; — transforms text to capitals
  • text-decoration: none; — removes underline from links
  • text-decoration: underline; — adds underline
  • line-height: 1.5em; — sets vertical gap between lines
  • letter-spacing: 0.1em; — sets gap between letters
  • word-spacing: 1em; — sets gap between words
  • text-align: left / center / right / justify; — aligns text
  • text-shadow: 2px 2px 5px #000000; — adds shadow behind text

Pseudo-Classes

  • a:link — unvisited link
  • a:visited — visited link
  • a:hover — element being hovered over
  • a:active — element being clicked
  • input:focus — input currently selected by user

Boxes

  • width: 300px; — sets width of element
  • height: 150px; — sets height of element
  • max-width: 800px; — maximum width element can grow to
  • padding: 10px; — space between content and border
  • margin: 20px; — space outside the border
  • margin: 0 auto; — centres a block element horizontally
  • border: 2px solid #ee3e80; — shorthand border
  • border-radius: 10px; — rounds corners
  • box-shadow: 5px 5px 10px #000000; — adds shadow to box
  • display: block; — makes element behave as block
  • display: inline; — makes element behave as inline
  • display: inline-block; — inline but accepts width and height
  • display: none; — hides element completely
  • overflow: hidden; — hides content that overflows the box
  • overflow: scroll; — adds scrollbar for overflowing content

Lists

  • list-style-type: none; — removes bullet points
  • list-style-type: square; — square bullet points
  • list-style-type: decimal; — numbered list
  • list-style-type: lower-alpha; — a, b, c list
  • list-style-position: inside; — bullet sits inside text flow

Tables

  • border-collapse: collapse; — merges adjacent cell borders
  • width: 100%; — makes table full width of container
  • padding: 10px; — adds space inside cells
  • text-align: left; — aligns cell content

Layout

  • position: static; — default, normal flow
  • position: relative; — moves from where it would have been
  • position: absolute; — takes out of flow, positions to nearest positioned ancestor
  • position: fixed; — stays in place when user scrolls
  • top / right / bottom / left: 0px; — offset values for positioned elements
  • z-index: 10; — controls stacking order of overlapping elements
  • float: left / right; — floats element, text flows around it
  • clear: both; — stops element sitting next to floated elements

Images

  • max-width: 100%; — prevents image overflowing its container
  • display: block; margin: 0 auto; — centres an image
  • background-image: url("images/photo.jpg"); — sets background image
  • background-repeat: no-repeat; — shows image once only
  • background-position: center top; — positions background image
  • background-image: linear-gradient(#ffffff, #ee3e80); — CSS gradient

Forms

  • input[type="text"] { ... } — targets text inputs only
  • input[type="submit"] { ... } — targets submit button only
  • cursor: pointer; — shows pointer cursor on hover
  • cursor: text; — shows text cursor on hover
