First Things First

Before we go into text structure, there are a couple of things to bear in mind. Tags known as markup provide extra meaning to your content — this allows the browser to show the user the appropriate structure.

There are two types of markup:

  • Structural markup — elements we use to describe headings and paragraphs
  • Semantic markup — provides extra info such as where emphasis is placed in a sentence, a quotation, or the meaning of acronyms

Headings

Headings are different sizes. We use them to give information about the rest of the text. h1 is the largest and h6 is the smallest.

<h1> This is the main heading </h1>
<h2> This heading is a bit smaller </h2>
<h3> This is smaller than h2 </h3>
<h4> Much smaller </h4>
<h5> Even smaller </h5>
<h6> Smallest </h6>

Paragraphs

A paragraph is one or more sentences that form a self contained unit. The p tag wraps around each paragraph like this:

<p> The cat sat on the mat with his blue toy. </p>

Bold and Italic

To make text appear bold we use the b tag. For italic we use the i tag.

<p> I like a bold appearance <b> like this </b> </p>
<p> I like an italic appearance <i> like this </i> </p>

Superscript and Subscript

sup is used for superscript — characters that should sit above the line such as suffixes or mathematical concepts like raising a number to a power.

sub is used for subscript — characters that sit below the line, commonly used for footnotes and chemical formulas such as H₂O.

<p> On the 10<sup>th</sup> of September </p>
<p> The amount of CO<sub>2</sub> in the air </p>

White Space

When a browser comes across two or more spaces next to each other it only displays one space. When it comes across a line break it also treats it as a single space. This is called white space collapsing.

Line Breaks and Horizontal Rules

br adds a line break in the middle of a paragraph. hr creates a break between themes. These are empty elements with only one tag.

<br /> — line break
<hr /> — horizontal rule

Semantic Markup

  • <strong> — indicates that the content is important
  • <em> — adds emphasis that subtly changes the meaning
  • <blockquote> — for longer quotes that take up an entire paragraph
  • <q> — for shorter quotes within a paragraph
  • <abbr> — lets you provide the full meaning as a tooltip on hover
  • <cite> — used to indicate where a citation is from
  • <dfn> — used to indicate the defining instance of a new term
  • <address> — used for contact details for the author of the page
  • <ins> — shows content inserted into a document, usually underlined
  • <del> — shows text deleted from a document, usually with a line through it
  • <s> — means something is no longer relevant but cannot be deleted

🔨 Now Let's Build!

Open your index.html file in Notepad — the same file we started in Chapter 1. We're going to add some text formatting to it. Add the highlighted code to your body section:

<h2>About Me</h2>
<p>My name is <strong>[your name]</strong> and I am learning HTML.</p>
<hr />
<h2>My Favourite Things</h2>
<p>I love <em>coding</em> and late nights.</p>
<p>Did you know water is H<sub>2</sub>O?</p>

Save in Notepad and refresh your browser. You should see bold text, italic text, a horizontal rule dividing sections, and a subscript in the chemical formula!

✅ Your full file should now look like this:

<!DOCTYPE html>
<html>
  <head>
    <title>My First Webpage</title>
  </head>
  <body>
    <h1>Welcome to My Page</h1>
    <p>I am learning to code and this is my first webpage!</p>
    <h2>About Me</h2>
    <p>My name is <strong>[your name]</strong> and I am learning HTML.</p>
    <hr />
    <h2>My Favourite Things</h2>
    <p>I love <em>coding</em> and late nights.</p>
    <p>Did you know water is H<sub>2</sub>O?</p>
  </body>
</html>

Chapter 2 Quiz

Only move on when you can answer all of these confidently without looking!

1. Which tag is used for the largest heading?

  • a) <h6>
  • b) <h3>
  • c) <h1>
  • d) <heading>

2. What does <br /> do?

  • a) Makes text bold
  • b) Creates a horizontal line
  • c) Adds a line break
  • d) Starts a new paragraph

3. Which tag would you use to show a chemical formula like H₂O?

  • a) <sup>
  • b) <small>
  • c) <sub>
  • d) <em>

4. What is the difference between <strong> and <b>?

  • a) There is no difference
  • b) <strong> means the content is important, <b> just makes it visually bold
  • c) <b> means the content is important, <strong> just makes it visually bold
  • d) <strong> is for headings only

5. Which tag would you use for a long quote that takes up a whole paragraph?

  • a) <q>
  • b) <quote>
  • c) <cite>
  • d) <blockquote>
