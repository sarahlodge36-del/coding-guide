Every Element Lives in a Box

At the beginning of this section on CSS, you saw how CSS treats each HTML element as if it lives in its own box. In this chapter we look at how to control the appearance of those boxes — their size, their borders, and the space around and inside them.

Box Dimensions — width, height

By default a box is sized just big enough to hold its contents. You can override this using the width and height properties. Values can be given in pixels, percentages, or ems.

div {
  width: 300px;
  height: 150px;
}

Border, Margin and Padding

Every box has three properties that can be adjusted to control the space around it.

Border — sits between the margin and the padding. You can set its width, style, and colour.

Margin — the gap between the border of one box and the border of the next. Margins are transparent.

Padding — the space between the content of a box and its border. Padding is also transparent, but it will reveal the background colour of the box.

Border Style and Colour

border-style controls the appearance of the border line.

p.one   { border-style: solid; }
p.two   { border-style: dotted; }
p.three { border-style: dashed; }

border-color sets the colour of the border using RGB, hex, or colour names.

p { border-color: #ee3e80; }

Shorthand Border

You can combine width, style, and colour into a single border property.

p {
  border: 3px dotted #ee3e80;
}

Padding

The padding property sets the space between the content of a box and its border.

p {
  padding: 10px;
}

Margin

The margin property controls the gap between boxes.

p {
  margin: 20px;
}

If the left and right margins are both set to auto the box will sit centrally within its containing element — which brings us neatly to the next bit.

Centering Content

To centre a box on the page, set a width and then set the left and right margins to auto. Without a width set, the box would stretch to fill the full width of the page and centering would have no effect.

p {
  width: 300px;
  margin: 0px auto;
}

CSS3: Round Corners — border-radius

CSS3 lets you round the corners of any box using border-radius. The value is the radius of the curve — the larger the value, the more rounded the corner.

p {
  border-radius: 10px;
}

CSS3: Box Shadow — box-shadow

Works similarly to text-shadow but applies to the whole box. Takes horizontal offset, vertical offset, blur, and colour.

div {
  box-shadow: 5px 5px 10px #666666;
}

Changing Inline/Block — display

The display property lets you change whether an element behaves as block level or inline, or hides it entirely.

li { display: inline; }
a  { display: block; }
p  { display: none; }

inline-block is particularly handy — it lets elements sit next to each other like inline elements, but still lets you set width and height like block elements.

Overflowing Content — overflow

If the content inside a box is larger than the box itself, you need to tell the browser what to do with it using the overflow property.

p { overflow: hidden; }
p.two { overflow: scroll; }

hidden simply hides any content that doesn't fit inside the box. scroll adds a scrollbar so the user can scroll to see the rest of the content.

🔨 Now Let's Build!

Open your styles.css file in Notepad. We're going to box off some sections of your page properly. Add this to your stylesheet:

#header {
  padding: 20px;
  border-bottom: 3px solid #ee3e80;
}

#content {
  max-width: 700px;
  margin: 20px auto;
  padding: 20px;
  border-radius: 10px;
  box-shadow: 0px 0px 15px rgba(0,212,255,0.3);
}

#footer {
  padding: 15px;
  text-align: center;
  border-top: 1px solid #444444;
}

Save and refresh your browser. Those div sections you wrapped in Chapter 8 — header, content, footer — now have real structure!

Chapter 13 Quiz

Only move on when you can answer all of these confidently without looking!

1. What is the difference between padding and margin?

  • a) There is no difference
  • b) Padding is the space between the content and the border; margin is the space between the border and the next element
  • c) Margin is the space between the content and the border; padding is the space between the border and the next element
  • d) Padding only works on block elements

2. How do you centre a box on the page using CSS?

  • a) Set text-align to center
  • b) Set padding to auto
  • c) Set a width and both left and right margins to auto
  • d) Set display to center

3. What does overflow: scroll do?

  • a) Hides any content that doesn't fit in the box
  • b) Removes the box from the page
  • c) Adds a scrollbar so the user can see the rest of the content
  • d) Stretches the box to fit the content

4. What does border-radius do?

  • a) Adds a shadow behind the box
  • b) Sets the thickness of the border
  • c) Rounds the corners of a box
  • d) Adds an image as a border

5. What does inline-block do that regular inline doesn't?

  • a) Makes an element invisible
  • b) Removes the element from the page flow
  • c) Lets elements sit next to each other while still allowing width and height to be set
  • d) Makes the element take up the full width of the page

6. When you give four values to padding or margin, what order do they go in?

  • a) Left, right, top, bottom
  • b) Top, bottom, left, right
  • c) Top, right, bottom, left
  • d) Right, left, top, bottom
