Making Decisions

Scripts often need to behave differently depending on the situation. Is the player's health above zero? Did they answer correctly? Is the inventory full? JavaScript uses conditional statements to make these kinds of decisions — checking whether something is true or false and running different code depending on the answer.

Comparison Operators

Before we look at if statements, we need to understand how JavaScript compares values. Comparison operators return either true or false.

  • === — strict equality. Is this exactly equal to that? (same value AND same type)
  • !== — strict inequality. Is this NOT equal to that?
  • > — is this greater than that?
  • < — is this less than that?
  • >= — is this greater than or equal to that?
  • <= — is this less than or equal to that?
3 === 3 // true
3 === '3' // false — different types
5 > 3 // true
2 < 1 // false

Always use === rather than == for comparisons in JavaScript. The double equals == does type coercion which can cause unexpected results. Strict equality === is safer and more predictable.

Logical Operators

Logical operators let you combine multiple conditions together.

  • && — AND. Both conditions must be true.
  • || — OR. At least one condition must be true.
  • ! — NOT. Reverses a boolean — true becomes false, false becomes true.
playerHealth > 0 && playerScore > 10 // true only if BOTH are true
playerHealth === 0 || gameOver // true if EITHER is true
!gameOver // true if gameOver is false

if Statements

An if statement evaluates a condition. If the condition is true, the code inside the curly braces runs. If it's false, the code is skipped.

if (playerHealth > 0) {
  showMessage('You are still in the game!');
}

if else Statements

You can add an else block to handle what happens when the condition is false.

if (playerHealth > 0) {
  showMessage('You are still in the game!');
} else {
  showMessage('Game over. Better luck next time!');
}

else if Statements

You can chain multiple conditions together using else if.

if (playerHealth === 3) {
  showMessage('Full health. Impressive.');
} else if (playerHealth === 2) {
  showMessage('One life down. Stay sharp.');
} else if (playerHealth === 1) {
  showMessage('Last life. No pressure.');
} else {
  showMessage('Game over.');
}

JavaScript checks each condition in order from top to bottom and runs the first one that is true. Once it finds a match it stops checking — so order matters.

Switch Statements

A switch statement is useful when you have many conditions all checking the same variable. It's neater than a long chain of else if statements.

switch (currentRealm) {
  case 1:
    showMessage('You enter the HTML Vault.');
    break;
  case 2:
    showMessage('You enter the CSS Labyrinth.');
    break;
  default:
    showMessage('Unknown realm.');
}

The break keyword stops the switch statement from running into the next case. Always include it unless you specifically want multiple cases to run together.

For Loops

A loop repeats a block of code a set number of times. A for loop has three parts — the initialiser (where you start), the condition (when to stop), and the update (what to change each time).

for (var i = 0; i < 5; i++) {
  console.log('Loop number ' + i);
}

This loop starts at 0, runs while i is less than 5, and adds 1 to i each time — so it runs 5 times total, with i being 0, 1, 2, 3, and 4.

While Loops

A while loop keeps running as long as a condition is true. Be careful — if the condition never becomes false, the loop runs forever and crashes the browser!

while (playerHealth > 0) {
  // game keeps running while player has health
  playerHealth--;
}

The -- operator subtracts 1 from a variable. The ++ operator adds 1. You'll see both constantly in loops.

Looping Through Arrays

One of the most common uses of loops is going through every item in an array.

var inventory = ['Structure Crystal', 'Style Gem', 'Logic Core'];

for (var i = 0; i < inventory.length; i++) {
  console.log(inventory[i]);
}

inventory.length gives you the number of items in the array. Using it in the loop condition means the loop always runs the right number of times even if the array changes.

// ==============================
// GAME VARIABLES
// ==============================
var playerName = '';
var playerHealth = 3;
var playerScore = 0;
var inventory = [];
var currentRealm = 0;

// ==============================
// REALM DATA
// ==============================
var realms = [
  {
    name: 'The HTML Vault',
    guardian: 'The Tag Keeper',
    reward: 'Structure Crystal',
    question: 'What does HTML stand for?',
    options: ['Hypertext Markup Language', 'High Transfer Machine Language', 'Hypertext Making Language', 'Hyper Transfer Markup Language'],
    correct: 0
  },
  {
    name: 'The CSS Labyrinth',
    guardian: 'The Style Witch',
    reward: 'Style Gem',
    question: 'Which CSS property makes text bold?',
    options: ['font-style: bold', 'text-weight: bold', 'font-weight: bold', 'bold: true'],
    correct: 2
  },
  {
    name: 'The JavaScript Jungle',
    guardian: 'The Logic Beast',
    reward: 'Logic Core',
    question: 'What is the correct way to declare a variable in JavaScript?',
    options: ['variable name = 5', 'var name = 5', 'v name = 5', 'declare name = 5'],
    correct: 1
  },
  {
    name: 'The Server Caves',
    guardian: 'The Dark Server',
    reward: 'Power Cell',
    question: 'What does DOM stand for?',
    options: ['Document Object Model', 'Data Object Method', 'Document Oriented Markup', 'Dynamic Object Model'],
    correct: 0
  },
  {
    name: 'The Cloud Tower',
    guardian: 'The Glitch',
    reward: 'Cloud Key',
    question: 'Which event fires when a user clicks a button?',
    options: ['onpress', 'ontouch', 'click', 'onbutton'],
    correct: 2
  }
];

// ==============================
// FUNCTIONS
// ==============================

function showMessage(text) {
  document.getElementById('message').textContent = text;
}

function showStory(text) {
  document.getElementById('story').textContent = text;
}

function showStats() {
  document.getElementById('stats').textContent = playerName + ' | Lives: ' + playerHealth + ' | Score: ' + playerScore + ' | Inventory: ' + (inventory.length === 0 ? 'empty' : inventory.join(', '));
}

function showChoices(choices) {
  var choicesDiv = document.getElementById('choices');
  choicesDiv.innerHTML = '';
  for (var i = 0; i < choices.length; i++) {
    var btn = document.createElement('button');
    btn.textContent = choices[i];
    btn.setAttribute('data-index', i);
    choicesDiv.appendChild(btn);
  }
}

function startGame() {
  var nameInput = document.getElementById('nameInput').value;
  if (nameInput === '') {
    showMessage('You need to enter your name, coder!');
  } else {
    playerName = nameInput;
    document.getElementById('input-area').style.display = 'none';
    showStory('Welcome, ' + playerName + '. I am XGENFUTBOT — your guide, your conscience, and occasionally your biggest critic. The Code Machine has been dismantled and its five components scattered across five dangerous realms. You must retrieve them all. Do you have what it takes?');
    showMessage('');
    showStats();
    showChoices(['I was born ready. Let\'s go.', 'I\'m terrified but let\'s do this anyway.']);
    document.getElementById('choices').setAttribute('data-mode', 'intro');
  }
}

function enterRealm() {
  var realm = realms[currentRealm];
  showStory('You enter ' + realm.name + '. The ' + realm.guardian + ' blocks your path. "Answer my question and the ' + realm.reward + ' is yours," it growls.');
  showMessage(realm.question);
  showChoices(realm.options);
  document.getElementById('choices').setAttribute('data-mode', 'question');
}

function handleAnswer(index) {
  var realm = realms[currentRealm];
  if (index === realm.correct) {
    inventory.push(realm.reward);
    playerScore += 100;
    showStats();
    currentRealm++;
    if (currentRealm < realms.length) {
      showStory('Correct! The ' + realm.reward + ' is yours. XGENFUTBOT nods approvingly. "Not bad. But there are ' + (realms.length - currentRealm) + ' realm' + (realms.length - currentRealm === 1 ? '' : 's') + ' left. Don\'t celebrate yet."');
      showMessage('');
      showChoices(['Continue to the next realm']);
      document.getElementById('choices').setAttribute('data-mode', 'continue');
    } else {
      endGame();
    }
  } else {
    playerHealth--;
    showStats();
    if (playerHealth === 0) {
      gameOver();
    } else {
      showStory('Hmm — not quite. But that\'s completely fine. Nobody gets everything first time. The important thing is that now you\'ve seen the right answer, it\'ll stick. You have ' + playerHealth + ' ' + (playerHealth === 1 ? 'life' : 'lives') + ' remaining. Try again!');
      showMessage(realm.question);
      showChoices(realm.options);
      document.getElementById('choices').setAttribute('data-mode', 'question');
    }
  }
}

function gameOver() {
  showStory('Hey — don\'t feel bad about this. Seriously. The fact that you got this far means you\'re already doing brilliantly. The section that tripped you up is worth one more read — not because you\'re behind, but because once it clicks it clicks forever.');
  showMessage('XGENFUTBOT tips his fedora. "Every developer has been exactly where you are right now. Every single one."');
  showChoices(['Try again from the beginning']);
  document.getElementById('choices').setAttribute('data-mode', 'restart');
}

function endGame() {
  var ending;
  if (playerHealth === 3) {
    ending = 'PERFECT RUN! The Code Machine roars to life, all five components locked in. XGENFUTBOT does an actual victory dance. "I knew you had it. Full marks, full lives, full brilliance. You are ready for what comes next."';
  } else if (playerHealth === 2) {
    ending = 'The Code Machine activates — a few sparks fly but it works. XGENFUTBOT nods. "Solid run. One stumble does not a failure make. You\'re ready."';
  } else {
    ending = 'The Code Machine splutters to life. XGENFUTBOT raises an eyebrow. "It works. Barely. But it works. Go back and review the bits that caught you out — then you\'ll be genuinely ready."';
  }
  showStory(ending);
  showMessage('🎉 Quest Complete! Final Score: ' + playerScore);
  document.getElementById('choices').innerHTML = '';
}

// ==============================
// EVENT LISTENERS
// ==============================

document.getElementById('startBtn').addEventListener('click', startGame);

document.getElementById('choices').addEventListener('click', function(e) {
  if (e.target.tagName !== 'BUTTON') return;
  var mode = document.getElementById('choices').getAttribute('data-mode');
  var index = parseInt(e.target.getAttribute('data-index'));
  if (mode === 'intro') {
    enterRealm();
  } else if (mode === 'question') {
    handleAnswer(index);
  } else if (mode === 'continue') {
    enterRealm();
  } else if (mode === 'restart') {
    playerHealth = 3;
    playerScore = 0;
    inventory = [];
    currentRealm = 0;
    enterRealm();
  }
});
