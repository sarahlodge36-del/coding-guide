Two Groups of Text Properties

The properties that allow you to control the appearance of text can be split into two groups — those that directly affect the font itself (the typeface, whether it's bold or italic, and the size), and those that affect the text regardless of font (colour, spacing between letters and words). Getting your text right has a huge impact on how readable your pages are.

Typeface Terminology

Before we get into the CSS properties, it helps to know a few terms.

Serif fonts have small decorative strokes at the ends of the main strokes of each letter. They're traditionally considered easier to read in print. Georgia and Times New Roman are serif fonts.

Sans-serif fonts don't have those extra strokes — the edges are clean and straight. Arial and Verdana are sans-serif. They tend to be cleaner on screens.

Monospace fonts give every character the same width. Courier is the classic example. They're commonly used for displaying code.

Specifying Typefaces — font-family

When you specify a font in CSS, the user's computer needs to have that font installed. If it doesn't, the browser falls back to a default. Because of this you can't just pick any font you like — you need to choose fonts that are likely to be installed, or use a font stack.

A font stack is a list of fonts in order of preference. The browser uses the first one it finds installed, and falls back to the next if it can't.

body { font-family: Georgia, "Times New Roman", serif; }

The last value in the stack should always be a generic family name — serif, sans-serif, or monospace — as a final fallback.

Units of Type Size

There are several ways to specify font size in CSS.

Pixels give you precise control and are the most common choice for screen design.

Percentages are relative to the default browser font size (usually 16px). So 75% would be 12px and 200% would be 32px.

Ems are also relative — 1em equals the current font size of the element. They're useful for scalable, accessible designs.

body { font-size: 16px; }
h1   { font-size: 200%; }
p    { font-size: 1.2em; }

Bold — font-weight

p { font-weight: bold; }

The font-weight property makes text bold. Values are bold or normal.

Italic — font-style

p { font-style: italic; }

Values are italic, oblique, or normal.

Upper and Lower Case — text-transform

h1 { text-transform: uppercase; }
p  { text-transform: lowercase; }
h2 { text-transform: capitalize; }

capitalize makes the first letter of each word a capital.

Underline and Strike — text-decoration

a  { text-decoration: none; }
h1 { text-decoration: underline; }
p  { text-decoration: line-through; }

Other values include overline and blink (though blink is best avoided — nobody wants flashing text).

Leading — line-height

Leading (pronounced "ledding") is the typographer's term for the vertical gap between lines of text. In CSS it's controlled with line-height. A value of around 1.4 to 1.5 times the font size is generally comfortable to read.

p { line-height: 1.5em; }

Letter and Word Spacing

Kerning is the term for the space between individual letters. In CSS you control this with letter-spacing. You can also adjust the gap between words with word-spacing.

h1 { letter-spacing: 0.2em; }
p  { word-spacing: 1em; }

These are best used sparingly — a subtle tweak rather than a dramatic change.

Alignment — text-align

h1      { text-align: left; }
p       { text-align: center; }
.outro { text-align: right; }

justify spreads text so both edges of each line are straight, like a newspaper column. Be careful with it on the web — it can create awkward gaps between words.

CSS3: Drop Shadow — text-shadow

CSS3 introduced text-shadow which adds a shadow behind text. It takes up to four values: horizontal offset, vertical offset, blur radius, and colour.

h1 {
  text-shadow: 2px 2px 5px #666666;
}

Styling Links — :link, :visited

These pseudo-classes let you style links depending on whether they've been visited or not.

a:link    { color: deeppink; }
a:visited { color: grey; }

Responding to Users — :hover, :active, :focus

:hover applies when the user moves their mouse over an element. :active applies when an element is being clicked. :focus applies when an element has keyboard focus.

a:hover   { color: deeppink; }
a:active  { color: darkcyan; }
input:focus { background-color: lightyellow; }

When using all of them on links, they should be written in this order: link, visited, hover, active — otherwise they may not work as expected.

🔨 Now Let's Build!

Open your styles.css file in Notepad. We're going to properly style your text. Add this to your stylesheet:

body {
  font-family: Arial, Verdana, sans-serif;
  background-color: #1a1a1a;
  color: #f0f0f0;
  line-height: 1.5em;
}

h1 {
  color: #ee3e80;
  text-transform: uppercase;
  letter-spacing: 0.1em;
  text-shadow: 2px 2px 5px #000000;
}

a:link {
  color: #00d4ff;
  text-decoration: none;
}

a:hover {
  text-decoration: underline;
}

Save and refresh your browser. Your heading should now have a drop shadow and be in capitals with extra letter spacing, your text should be more comfortable to read with the added line height, and your links should be blue with an underline appearing only when you hover over them!
