Advanced Cheat Sheet

The advanced reference sheet. Keep this one close. 😎

Advanced Semantic Elements

  • <main> — the primary content of the page. Only one per page.
  • <time datetime="2024-01-15"> — marks up dates and times in a machine readable way
  • <mark> — highlights text
  • <details> — collapsible section, no JavaScript needed
  • <summary> — the visible heading of a details element
  • <dialog> — a built-in modal dialog element
  • <progress value="70" max="100"> — a built-in progress bar
  • <meter min="0" max="100" value="75"> — a scalar measurement within a range
  • <template> — holds HTML that is not rendered but can be cloned by JavaScript

ARIA Attributes

  • role="button" — tells screen readers an element behaves like a button
  • role="navigation" — identifies a navigation landmark
  • role="alert" — announces dynamic content to screen readers immediately
  • aria-label="Close menu" — provides a text label for elements with no visible text
  • aria-hidden="true" — hides decorative elements from screen readers
  • aria-expanded="false" — whether a collapsible element is open or closed
  • aria-live="polite" — announces dynamic content changes politely
  • aria-live="assertive" — announces changes immediately interrupting other content
  • aria-describedby="id" — links an element to a description elsewhere on the page
  • aria-required="true" — tells screen readers a field is required
  • aria-disabled="true" — tells screen readers an element is disabled
  • tabindex="0" — makes a non-interactive element focusable via keyboard
  • tabindex="-1" — removes an element from the tab order

Meta Tags

  • <meta name="description" content="..."> — page description for search results
  • <meta name="robots" content="index, follow"> — search engine indexing instructions
  • <meta name="author" content="Sarah"> — page author
  • <meta name="theme-color" content="#0a0a0a"> — browser chrome colour on mobile
  • <meta name="viewport" content="width=device-width, initial-scale=1.0"> — responsive scaling
  • <link rel="canonical" href="https://yoursite.com/page"> — definitive URL for the page
  • <link rel="icon" href="favicon.ico"> — page favicon
  • <link rel="preload" href="font.woff2" as="font"> — preloads a resource for performance

Open Graph Tags

  • <meta property="og:title" content="Page Title"> — title shown in social media previews
  • <meta property="og:description" content="..."> — description in social media previews
  • <meta property="og:image" content="https://..."> — preview image
  • <meta property="og:url" content="https://..."> — canonical URL
  • <meta property="og:type" content="website"> — type of content
  • <meta name="twitter:card" content="summary_large_image"> — Twitter card type
  • <meta name="twitter:title" content="Page Title"> — Twitter specific title

Advanced Form Attributes

  • required — prevents form submission if field is empty
  • placeholder="hint text" — shows hint text inside the input
  • autocomplete="email" — hints to browser what to autofill
  • pattern="[0-9]{5}" — validates input against a regular expression
  • min="0" max="100" — minimum and maximum values on number inputs
  • step="5" — increment step for number inputs
  • disabled — disables an input
  • readonly — makes an input read only
  • autofocus — automatically focuses this input on page load
  • multiple — allows multiple file uploads or email addresses
  • type="email" — validates email format
  • type="tel" — shows numeric keyboard on mobile
  • type="date" — shows a date picker
  • type="range" — shows a slider
  • type="color" — shows a colour picker
  • type="search" — search input with clear button
  • type="number" — numeric input with up/down arrows
  • type="file" — file upload input
  • type="hidden" — hidden field, not shown to user

Data Attributes

  • data-index="0" — stores custom data on an element
  • data-mode="question" — any name after data- is valid
  • element.getAttribute('data-index') — reads a data attribute
  • element.setAttribute('data-index', 1) — sets a data attribute
  • element.dataset.index — reads via the dataset property
  • element.dataset.mode = 'answer' — sets via the dataset property

Responsive Images

  • srcset="photo-400.jpg 400w, photo-800.jpg 800w" — provides multiple image sizes
  • sizes="(max-width: 600px) 400px, 800px" — tells browser which size to use
  • <picture> — container for multiple image sources
  • <source media="(min-width: 800px)" srcset="large.jpg"> — source inside picture
  • loading="lazy" — defers loading images until they're near the viewport
  • decoding="async" — allows browser to decode image asynchronously

iframes

  • <iframe src="url"></iframe> — embeds another page
  • width="560" height="315" — sets iframe dimensions
  • allowfullscreen — allows fullscreen mode
  • allow="autoplay" — grants specific permissions
  • sandbox — restricts iframe capabilities for security
  • title="Video description" — required for accessibility
  • loading="lazy" — defers loading until near the viewport
