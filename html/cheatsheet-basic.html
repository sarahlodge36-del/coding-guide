HTML Cheat Sheet

Everything you've learned so far in one place. Bookmark this. You're welcome. 😎

Document Structure

  • <!DOCTYPE html> — declares the document as HTML5
  • <html> — the root element of the page
  • <head> — contains information about the page, not shown in the browser
  • <title> — the title shown in the browser tab
  • <body> — everything shown in the browser window

Headings

  • <h1> — largest heading
  • <h2> — subheading
  • <h3> — smaller subheading
  • <h4> — even smaller
  • <h5> — smaller still
  • <h6> — smallest heading

Text

  • <p> — paragraph
  • <b> — bold text (visual only)
  • <i> — italic text (visual only)
  • <strong> — bold — semantic importance
  • <em> — italic — semantic emphasis
  • <sup> — superscript (e.g. 10th, E=mc2)
  • <sub> — subscript (e.g. H₂O)
  • <br /> — line break
  • <hr /> — horizontal rule / divider
  • <blockquote> — long quote that takes up a whole paragraph
  • <q> — short inline quote
  • <abbr> — abbreviation with tooltip
  • <cite> — citation
  • <dfn> — defining instance of a new term
  • <address> — contact details for page author
  • <ins> — inserted content (underlined)
  • <del> — deleted content (strikethrough)
  • <s> — no longer relevant content

Lists

  • <ul> — unordered list (bullet points)
  • <ol> — ordered list (numbered)
  • <li> — list item
  • <dl> — definition list
  • <dt> — definition term
  • <dd> — definition description

Links

  • <a href="URL"> — hyperlink to a URL
  • <a href="mailto:?"> — email link
  • <a href="#id"> — link to anchor on same page
  • <a target="_blank"> — opens link in a new tab
  • id="name" — creates an anchor target on any element

Images

  • <img src=? alt=?> — embeds an image
  • src — path to the image file
  • alt — text description for screen readers and SEO
  • title — tooltip shown on hover
  • width and height — size in pixels

Tables

  • <table> — creates the table
  • <tr> — table row
  • <td> — table data cell
  • <th> — table header cell (bold, centred)
  • <thead> — table header group
  • <tbody> — table body group
  • <tfoot> — table footer group
  • colspan=? — cell spanning multiple columns
  • rowspan=? — cell spanning multiple rows

Forms

  • <form action=? method=?> — form container
  • <input type="text"> — single-line text input
  • <input type="password"> — password input (masked)
  • <input type="radio"> — radio button (one from group)
  • <input type="checkbox"> — checkbox
  • <input type="submit"> — submit button
  • <textarea> — multi-line text input
  • <select> — dropdown list
  • <option> — option within a dropdown
  • <label> — label linked to an input
  • <fieldset> — groups related form fields
  • <legend> — caption for a fieldset

Extra Markup

  • <!DOCTYPE html> — always at the top of every HTML page
  • <!-- comment --> — HTML comment, not shown in browser
  • <div> — block level container (no semantic meaning)
  • <span> — inline container (no semantic meaning)
  • &lt; — displays <
  • &gt; — displays >
  • &amp; — displays &
  • &copy; — displays ©
  • &nbsp; — non-breaking space

Video and Audio

  • <video> — embeds a video player
  • <audio> — embeds an audio player
  • <source src=? type=?> — media source within video/audio
  • controls — shows built-in play/pause controls
  • autoplay — plays automatically on load
  • loop — loops when finished
  • poster — image shown before video plays
  • preload — none, auto, or metadata

Key Attributes

  • id="name" — unique identifier for an element
  • class="name" — CSS class (reusable)
  • href="URL" — link destination
  • src="path" — source file path
  • alt="text" — alternative text description
  • name="name" — name of a form control
  • value="value" — value sent to server from form control
  • target="_blank" — opens link in new tab
  • action="URL" — where form data is sent
  • method="get/post" — how form data is sent
  • maxlength="n" — maximum characters in an input
  • checked — pre-selects a checkbox or radio button
  • selected — pre-selects a dropdown option
