Controlling Where Things Sit on the Page

In this chapter we look at how to control where each element sits on a page. This involves understanding how to position elements using CSS, and how designers create attractive page layouts.

Normal Flow — position: static

This is the default. You don't need to write it explicitly — it's what every element does unless you tell it otherwise. Each block element sits below the previous one, and inline elements sit within the text flow.

p { position: static; }

Relative Positioning — position: relative

Moves an element relative to where it would have been in normal flow. The space it would have occupied is still reserved — other elements don't move to fill it.

p {
  position: relative;
  top: 10px;
  left: 100px;
}

Absolute Positioning — position: absolute

Takes the element completely out of normal flow. Other elements on the page behave as if it isn't there at all. The element is positioned relative to its nearest positioned ancestor — or the body if none exists.

h1 {
  position: absolute;
  top: 0px;
  left: 500px;
}

Fixed Positioning — position: fixed

A form of absolute positioning that positions the element relative to the browser window rather than the page. This means it stays in the same place even when the user scrolls. Useful for fixed headers and navigation bars.

h1 {
  position: fixed;
  top: 0px;
  left: 0px;
  width: 100%;
}

Overlapping Elements — z-index

When elements are taken out of normal flow they can overlap each other. The z-index property controls which element sits on top. A higher z-index means the element sits in front.

h1 { z-index: 10; }
p  { z-index: 5; }

Floating Elements — float

The float property takes an element out of normal flow and positions it to the far left or far right of its containing box. Other content then flows around it. You must also set a width on floated elements — otherwise they take up the full width of the container.

img {
  float: left;
  width: 200px;
  margin: 10px;
}

Creating Multi-Column Layouts with Floats

Float was the classic CSS technique for creating multi-column layouts before flexbox and grid came along. By floating multiple elements left you can get them to sit next to each other.

.column {
  float: left;
  width: 45%;
  margin: 10px;
}

Clearing Floats — clear

Once you start floating elements, things that follow can end up in unexpected places. The clear property tells an element to move below any floated elements to its left, right, or both sides.

p { clear: left; }
p { clear: right; }
p { clear: both; }

Fixed Width vs Liquid Layouts

A fixed width layout sets the width of the page in pixels so it stays the same regardless of the browser window size. A liquid layout uses percentages for widths rather than pixels, so the page stretches and shrinks to fill the available browser window.

/* Fixed width */
body { width: 960px; margin: 0 auto; }

/* Liquid */
body { width: 90%; margin: 0 auto; }

🔨 Now Let's Build!

Open your styles.css file in Notepad. We're going to give your page an overall maximum width so it doesn't stretch endlessly on wide screens. Add this to your stylesheet:

body {
  max-width: 800px;
  margin: 0 auto;
}

header {
  position: relative;
}

Save and refresh your browser. Your whole page now sits centred with a maximum width — even on a huge monitor it won't stretch uncomfortably wide.

Chapter 15 Quiz

Only move on when you can answer all of these confidently without looking!

1. What is normal flow?

  • a) A CSS property that controls the layout
  • b) The default way browsers lay out elements — block elements stacking on top of each other
  • c) A type of float layout
  • d) A fixed width layout technique

2. What is the difference between relative and absolute positioning?

  • a) There is no difference
  • b) Relative moves an element from where it would have been and keeps its space; absolute takes it out of normal flow entirely
  • c) Absolute moves an element from where it would have been and keeps its space; relative takes it out of normal flow entirely
  • d) Relative positioning only works on images

3. What does position: fixed do?

  • a) Fixes an element in place relative to its parent
  • b) Removes an element from the page entirely
  • c) Keeps an element in the same place in the browser window even when the user scrolls
  • d) Prevents an element from being floated

4. What does the z-index property control?

  • a) The width of an element
  • b) The transparency of an element
  • c) Which overlapping element sits on top
  • d) The zoom level of the page

5. What must you always set on a floated element?

  • a) A height
  • b) A width
  • c) A margin
  • d) A z-index

6. What does clear: both do?

  • a) Removes all styles from an element
  • b) Floats an element to both sides
  • c) Tells an element to move below any floated elements on either side
  • d) Clears the browser cache

7. What is the difference between a fixed width and a liquid layout?

  • a) Fixed layouts use percentages; liquid layouts use pixels
  • b) Fixed layouts use pixels and stay the same width; liquid layouts use percentages and stretch to fill the browser window
  • c) Liquid layouts only work on mobile devices
  • d) There is no practical difference
