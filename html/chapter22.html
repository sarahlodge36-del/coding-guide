Functions, Methods and Objects

Functions are reusable blocks of code. Write once, use everywhere. This is where things get elegant. 😎

What is a Function?

A function is a group of statements that together perform a specific task. Instead of writing the same code over and over again, you write it once inside a function and then call that function whenever you need it.

Think of a function like a named recipe. You write the recipe once — "how to make tea" — and then whenever you want tea you just say "make tea" rather than listing every step again from scratch.

Functions are one of the most important concepts in JavaScript. Almost everything you build will use them.

Declaring a Function

To create a function you use the function keyword, give it a name, add parentheses, and then put the code it should run inside curly braces.

function sayHello() {
  var greeting = 'Hello there!';
  alert(greeting);
}

That function is now declared — but it won't do anything yet. It just sits there waiting to be called.

Calling a Function

To make a function actually run, you call it by writing its name followed by parentheses.

sayHello();

That one line runs all the code inside the sayHello function. You can call the same function as many times as you like from anywhere in your script.

Functions with Parameters

Functions can accept information when they're called. The named variables inside the parentheses of a function declaration are called parameters. When you call the function and pass values in, those values are called arguments.

function greetPlayer(name) {
  alert('Welcome, ' + name + '!');
}

greetPlayer('Sarah'); // shows "Welcome, Sarah!"
greetPlayer('Jack'); // shows "Welcome, Jack!"

The same function works differently depending on what you pass in. That's what makes functions so powerful.

Functions that Return a Value

Some functions calculate something and send the result back. The return keyword does this. Once a function hits a return statement it stops running and sends the value back to wherever it was called from.

function calculateArea(width, height) {
  var area = width * height;
  return area;
}

var roomArea = calculateArea(5, 3); // roomArea is now 15

Variable Scope

Variables declared inside a function are only available inside that function. This is called local scope. Variables declared outside any function are available anywhere in the script — this is called global scope.

var playerName = 'Sarah'; // global — available everywhere

function showScore() {
  var bonus = 50; // local — only exists inside this function
  alert(playerName + ' scored ' + bonus + ' points!');
}

If you try to access a local variable outside its function, JavaScript won't know what you're talking about and will throw an error. This is actually a good thing — it keeps your code tidy and prevents variables from interfering with each other.

Methods

A method is simply a function that belongs to an object. You've already been using methods without realising it.

document.getElementById('title'); // getElementById is a method
console.log('Hello'); // log is a method of console
inventory.push('Structure Crystal'); // push is a method of arrays

The dot between the object and the method name is called dot notation. Object dot method. You'll see this pattern constantly — it's one of the most important patterns in JavaScript.

Objects

An object is a collection of related variables and functions grouped together under one name. The variables inside an object are called properties and the functions inside are called methods.

var player = {
  name: 'Sarah',
  health: 3,
  score: 0,
  inventory: [],
  greet: function() {
    return 'Hello, ' + this.name + '!';
  }
};

You access an object's properties and methods using dot notation:

player.name; // 'Sarah'
player.health; // 3
player.greet(); // 'Hello, Sarah!'

The this keyword inside an object refers to the object itself. So this.name means "the name property of this object."

🔨 Now Let's Build!

Open your Code Machine Quest CodePen. We're going to reorganise the game using functions so each part of the game has its own job. This makes the code much cleaner and easier to build on in later chapters.

Replace everything in your JS panel with this:

// ==============================
// GAME VARIABLES
// ==============================
var playerName = '';
var playerHealth = 3;
var playerScore = 0;
var inventory = [];
var currentRealm = 0;

// ==============================
// FUNCTIONS
// ==============================

// Shows a message in the message box
function showMessage(text) {
  document.getElementById('message').textContent = text;
}

// Updates the title on screen
function showTitle(text) {
  document.getElementById('title').textContent = text;
}

// Shows the player's current stats
function showStats() {
  return playerName + ' | Lives: ' + playerHealth + ' | Score: ' + playerScore;
}

// Starts the game when the button is clicked
function startGame() {
  var nameInput = document.getElementById('nameInput').value;
  if (nameInput === '') {
    showMessage('You need to enter your name, coder!');
  } else {
    playerName = nameInput;
    showTitle('THE CODE MACHINE QUEST');
    showMessage('Welcome, ' + playerName + '. XGENFUTBOT is watching. The quest begins...');
  }
}

// ==============================
// EVENT LISTENERS
// ==============================
document.getElementById('startBtn').addEventListener('click', startGame);

Notice what's changed — instead of writing all the code inside the button click directly, we now have separate functions that each do one specific job. showMessage() updates the message box. showStats() builds the stats string. startGame() runs when the button is clicked and calls the other functions to do the work.

Test it — type your name and click Begin the Quest. It should work exactly the same as before. But the code underneath is now much better organised. 🚀

1. What is a function?

  • a) A type of variable
  • b) A group of statements that together perform a specific task
  • c) A CSS property
  • d) A way of storing data in an array

2. What is the difference between a parameter and an argument?

  • a) There is no difference — they mean the same thing
  • b) A parameter is the named variable in the function declaration; an argument is the actual value passed in when the function is called
  • c) An argument is declared in the function; a parameter is passed in when called
  • d) Parameters are for methods; arguments are for functions

3. What does the return keyword do?

  • a) Sends the user back to the previous page
  • b) Restarts the function from the beginning
  • c) Stops the function and sends a value back to wherever the function was called from
  • d) Declares a new variable

4. What is the difference between local scope and global scope?

  • a) There is no difference
  • b) Local scope means a variable only exists inside the function it was declared in; global scope means it's available everywhere in the script
  • c) Global scope means a variable only exists inside a function; local scope means it's available everywhere
  • d) Local variables are faster than global variables

5. What is a method?

  • a) A type of variable that stores a list
  • b) A way of declaring a function
  • c) A function that belongs to an object
  • d) A CSS property applied with JavaScript

6. What does the this keyword refer to inside an object?

  • a) The global window object
  • b) The previous function that was called
  • c) The object itself
  • d) The HTML element the script is attached to
