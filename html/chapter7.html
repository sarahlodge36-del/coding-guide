What is a Form?

Traditionally the word form referred to a printed document with spaces for you to fill in. HTML borrows this idea — a form on a webpage is a way of collecting information from your visitors. Whether it's a simple search box or a full sign-up page, forms give you the tools to gather data from your users.

The best known form on the web is probably the search box sitting right in the middle of Google's homepage.

How Forms Work

A user fills in a form and clicks a button to submit the information to the server. Here's what happens step by step:

  • The user fills in the form and hits submit
  • The name of each form control is sent to the server along with the value the user entered
  • The server processes the information
  • The server creates a new page to send back based on the information received

Each form control is given a name, and the data is sent in name/value pairs — for example username=Sarah or vote=yes.

Form Structure

All form controls live inside a form element. It should always carry an action attribute and will usually have a method attribute too.

  • action — the URL of the page on the server that will receive the information
  • method — get or post. Use get for short forms and simple data retrieval. Use post for sensitive data, file uploads, or long forms
<form action="http://www.example.com/subscribe.php" method="get">
  <p>This is where the form controls will appear.</p>
</form>

Text Input

The input element is used to create several different form controls. The type attribute determines what kind of input it creates. type="text" creates a single-line text input.

<form action="http://www.example.com/login.php">
  <p>Username:
    <input type="text" name="username" maxlength="30" />
  </p>
</form>

Password Input

type="password" works just like a text input except the characters are hidden as you type. Remember though — this doesn't mean the data is sent securely. For real security the server needs to use SSL.

<input type="password" name="password" maxlength="30" />

Text Area

textarea is used for multi-line text input — things like comments or messages. Unlike input it is not an empty element, so it needs both an opening and a closing tag.

<textarea name="comments">Enter your comments...</textarea>

Radio Buttons

Radio buttons let the user pick just one option from a group. All radio buttons in the same group must share the same name attribute. Each one needs a different value so the server knows which option was chosen.

<input type="radio" name="genre" value="rock" checked="checked" /> Rock
<input type="radio" name="genre" value="pop" /> Pop
<input type="radio" name="genre" value="jazz" /> Jazz

Checkboxes

Checkboxes let users select and deselect one or more options. Like radio buttons, all checkboxes answering the same question share the same name.

<input type="checkbox" name="service" value="itunes" checked="checked" /> iTunes
<input type="checkbox" name="service" value="spotify" /> Spotify

Drop-Down List

A drop-down list lets users pick one option from a list. Use radio buttons when you want users to see all options at once. Use a drop-down when the list is long.

<select name="devices">
  <option value="ipod">iPod</option>
  <option value="radio">Radio</option>
  <option value="computer">Computer</option>
</select>

Submit Button

The submit button sends the form data to the server. Use the value attribute to control the text that appears on the button.

<input type="submit" name="subscribe" value="Subscribe" />

Labelling Form Controls

Each form control should have a label element to tell users what information to enter. This also makes forms accessible to screen readers. A label can wrap around the form control, or be linked using the for attribute — its value should match the id of the form control.

<label>Age: <input type="text" name="age" /></label>

Grouping Form Elements

You can group related form controls together using fieldset. Most browsers draw a line around the group. The legend element sits directly after the opening fieldset tag and gives the group a caption.

<fieldset>
  <legend>Contact details</legend>
  <label>Email:<br />
    <input type="text" name="email" /></label>
</fieldset>

🔨 Now Let's Build!

Open your index.html file in Notepad. We're going to add a simple contact form. Add the following code after your existing content inside the body tags:

<h2>Contact Me</h2>
<form action="mailto:your@email.com" method="get">
  <fieldset>
    <legend>Your Details</legend>
    <label>Name:<br />
      <input type="text" name="name" maxlength="100" />
    </label><br />
    <label>Email:<br />
      <input type="text" name="email" maxlength="100" />
    </label><br />
    <label>Message:<br />
      <textarea name="message"></textarea>
    </label><br />
    <input type="submit" value="Send Message" />
  </fieldset>
</form>

Save and refresh your browser. You should see a simple contact form on your page! 🚀

Chapter 7 Quiz

Only move on when you can answer all of these confidently without looking!

1. Which element do all form controls live inside?

  • a) <input>
  • b) <fieldset>
  • c) <form>
  • d) <label>

2. What does the action attribute on a form element do?

  • a) Decides whether to use get or post
  • b) Specifies the URL that will receive the form data
  • c) Labels the form controls
  • d) Groups related form fields together

3. Which input type would you use to collect a password?

  • a) type="text"
  • b) type="hidden"
  • c) type="secret"
  • d) type="password"

4. What is the difference between radio buttons and checkboxes?

  • a) There is no difference
  • b) Radio buttons let you pick one option; checkboxes let you pick one or more
  • c) Checkboxes let you pick one option; radio buttons let you pick many
  • d) Radio buttons don't need a name attribute

5. Which element is used to group related form controls together?

  • a) <group>
  • b) <section>
  • c) <fieldset>
  • d) <label>
