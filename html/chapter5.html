Why Add Images?

There are many reasons why you might want to add an image to a web page — a logo, photograph, illustration, diagram, or chart. Taking time to get your images right will make your site look more attractive and professional.

Images should be relevant, convey information, convey the right mood, be instantly recognisable, and fit the colour palette of your site. Remember — all images are subject to copyright.

Storing Images on Your Site

Create a dedicated images folder for all the images your site uses. This keeps things organised and makes your file paths easier to manage.

Adding Images

We use the img tag to add images. It is an empty element — it has no closing tag. It needs at least two attributes: src and alt.

  • src — tells the browser where to find the image
  • alt — provides a text description for screen readers and search engines
  • title — provides additional info shown as a tooltip on hover
<img src="images/cat.jpg"
     alt="A ginger cat sitting on a windowsill"
     title="Our cat Marmalade" />

Height and Width

You can set the size of an image using the width and height attributes. Values are in pixels.

<img src="images/cat.jpg"
     alt="A ginger cat"
     width="400"
     height="300" />

Where to Place Images in Your Code

  • Before a paragraph — the paragraph starts on a new line after the image
  • Inside the start of a paragraph — the first row of text aligns with the bottom of the image
  • In the middle of a paragraph — the image sits between the words

Remember — block elements always appear on a new line. Inline elements sit within a block element and do not start on a new line. Images are inline elements by default.

Three Rules for Creating Images

  • Save in the right format
  • Save at the right size
  • Measure in pixels

Image Formats

  • JPEG — best for photographs or images with many colours
  • GIF — best for flat colours, logos, and illustrations
  • PNG — best for flat colours or when transparency is needed

🔨 Now Let's Build!

Open your index.html file in Notepad. First create an images folder in the same place as your index.html file. Find a photo you like and save it into that images folder as myphoto.jpg.

Then add the following code after your existing content inside the body tags:

<h2>A Photo I Like</h2>
<img src="images/myphoto.jpg"
     alt="A photo I chose"
     width="400"
     height="300" />

Save and refresh your browser. You should see your image appearing on the page! If it doesn't show up check the file name matches exactly — including the extension.
