Controlling Images with CSS

Controlling the size and alignment of your images using CSS keeps all the presentation rules in your stylesheet and out of your HTML markup — which is exactly where they should be. You can also achieve some really interesting effects using background images.

Controlling Size — width, height

Rather than setting width and height directly on the img tag in your HTML, you can control image size in your CSS using a class name.

img.large {
  width: 500px;
}

img.small {
  width: 100px;
}

Aligning Images — float

The float property is the standard way to align images left or right so that text flows around them.

img.align-left {
  float: left;
  margin-right: 10px;
}

Always add a margin to the side the text will flow along, otherwise the text will sit right up against the image with no breathing room.

Centering Images

Images are inline elements by default, so to centre one you first need to turn it into a block level element, then use margin: 0 auto.

img.center {
  display: block;
  margin: 0 auto;
}

Background Image — background-image

The background-image property lets you place an image behind any HTML element — the whole page, a single div, a heading, anything.

body {
  background-image: url("images/pattern.gif");
}

Repeating Images — background-repeat

By default a background image will repeat to fill the entire element. You can control this with background-repeat.

body { background-repeat: repeat; }
body { background-repeat: no-repeat; }

Background Position — background-position

When an image isn't being repeated, you can control where it sits within its element using background-position.

body { background-position: center top; }
body { background-position: right bottom; }

CSS3 Gradients — background-image

CSS3 lets you create gradients directly in CSS without needing an image file at all. A linear gradient goes from one colour to another in a straight line.

div {
  background-image: linear-gradient(#ffffff, #ee3e80);
}

You actually saw this in action on the Welcome to CSS page — that blue to pink gradient box was exactly this in action!

Contrast of Background Images

If you want to place text over a background image, contrast is critical. A busy or bright image will make text almost impossible to read. There are a few ways to handle this — use a low contrast image, add a semi-transparent overlay between the image and the text using rgba, or apply a CSS filter to reduce the image's contrast.

🔨 Now Let's Build!

Open your styles.css file in Notepad. We're going to give your photo some proper sizing and alignment. Add this to your stylesheet:

img {
  max-width: 100%;
  border-radius: 10px;
  display: block;
  margin: 15px auto;
  box-shadow: 0px 0px 15px rgba(0,212,255,0.3);
}

Save and refresh your browser. Your photo should now be centred, have soft rounded corners, and a subtle glowing shadow around it!

  • d) CSS image sizes are more accurate

2. How do you float an image to the left so text flows around it?

  • a) text-align: left
  • b) position: left
  • c) float: left
  • d) align: left

3. What two things do you need to do to centre an image using CSS?

  • a) Set float to none and margin to auto
  • b) Set display to block and margin to 0 auto
  • c) Set position to center and width to 50%
  • d) Set text-align to center and display to inline

4. What does background-repeat: no-repeat do?

  • a) Repeats the image both horizontally and vertically
  • b) Repeats the image vertically only
  • c) Shows the image once only
  • d) Repeats the image horizontally only

5. Why is contrast important when placing text over a background image?

  • a) It makes the page load faster
  • b) Low contrast between text and image makes the text hard or impossible to read
  • c) High contrast causes images to pixelate
  • d) Contrast only matters for background colours not images
