CSS Has Grown Up

The CSS you learned in Chapters 10 to 19 covers the foundations — colour, text, boxes, layout with floats, and positioning. But modern CSS is significantly more powerful than that. Flexbox and Grid alone have transformed how layouts are built. Animations, custom properties, and responsive design techniques have made CSS into a genuinely sophisticated language.

This page is an overview of what's waiting for you beyond the basics. Some of these are covered in detail in the paid section of this guide. All of them are worth knowing exist.

Flexbox

Flexbox is a layout method that makes it easy to arrange elements in a row or column, align them, and distribute space between them. It replaced the old float-based layout technique for most use cases and is now the standard way to build navigation bars, card layouts, and any horizontal or vertical arrangement of elements.

.container {
  display: flex;
  justify-content: space-between; /* horizontal alignment */
  align-items: center; /* vertical alignment */
  gap: 20px; /* space between items */
}

Key flexbox properties:

  • display: flex — turns an element into a flex container
  • flex-direction: row / column — arranges children horizontally or vertically
  • justify-content — aligns children along the main axis
  • align-items — aligns children along the cross axis
  • flex-wrap: wrap — allows children to wrap onto multiple lines
  • gap — sets the space between flex children
  • flex: 1 — on a child, makes it grow to fill available space

CSS Grid

CSS Grid is a two-dimensional layout system — it lets you control both rows and columns at the same time. Where Flexbox is great for one-dimensional layouts (a row OR a column), Grid is designed for two-dimensional layouts (rows AND columns simultaneously).

.grid-container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* three equal columns */
  grid-template-rows: auto; /* rows size to content */
  gap: 20px;
}

Key grid properties:

  • display: grid — turns an element into a grid container
  • grid-template-columns — defines the number and size of columns
  • grid-template-rows — defines the number and size of rows
  • fr — a fractional unit — 1fr means one share of available space
  • gap — space between grid cells
  • grid-column: 1 / 3 — makes an item span across columns
  • repeat(3, 1fr) — shorthand for repeating column definitions

Media Queries and Responsive Design

A media query applies CSS rules only when certain conditions are met — most commonly when the browser window is a certain width. This is the foundation of responsive design — making your page look good on any screen size.

/* Default styles — mobile first */
.container {
  flex-direction: column;
}

/* Tablet and above */
@media (min-width: 768px) {
  .container {
    flex-direction: row;
  }
}

/* Desktop and above */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
  }
}

The mobile first approach — writing default styles for small screens and then adding styles for larger screens using min-width — is considered best practice. It forces you to prioritise content and results in cleaner code.

CSS Custom Properties — Variables

CSS variables let you store values in one place and reuse them throughout your stylesheet. If you want to change your brand colour you change it once in one place rather than hunting through hundreds of lines of CSS.

:root {
  --primary: #ff2d78;
  --secondary: #00d4ff;
  --bg: #0a0a0a;
  --text: #f0f0f0;
  --spacing: 20px;
}

h1 { color: var(--primary); }
body { background-color: var(--bg); }
.card { padding: var(--spacing); }

Variables are declared on the :root selector (which targets the html element) so they're available everywhere. JavaScript can also read and change CSS variables — making them a powerful bridge between your styles and your scripts.

Transitions

CSS transitions make property changes animate smoothly rather than jumping instantly. You define which property to animate, how long it should take, and the timing function.

button {
  background-color: transparent;
  transition: background-color 0.3s ease;
}

button:hover {
  background-color: #ff2d78;
}

You can transition multiple properties at once by separating them with commas, or use transition: all 0.3s ease to transition everything — though all can be inefficient on complex pages.

Animations and Keyframes

While transitions animate between two states, animations can go through multiple stages and run automatically without user interaction.

@keyframes pulse {
  0%   { opacity: 1; transform: scale(1); }
  50%  { opacity: 0.5; transform: scale(1.05); }
  100% { opacity: 1; transform: scale(1); }
}

.glow-element {
  animation: pulse 2s ease infinite;
}

Key animation properties:

  • animation-name — which keyframe to use
  • animation-duration — how long one cycle takes
  • animation-timing-function — ease, linear, ease-in-out etc
  • animation-iteration-count — how many times to run (or infinite)
  • animation-delay — wait before starting
  • animation-direction — normal, reverse, alternate

Pseudo-Elements — ::before and ::after

Pseudo-elements let you insert content before or after an element's content using CSS alone — no extra HTML needed. They're incredibly useful for decorative elements, badges, and visual effects.

.card::before {
  content: '⚡'; /* required — even if empty */
  display: block;
  font-size: 2rem;
  margin-bottom: 10px;
}

.required-field::after {
  content: ' *';
  color: #ff2d78;
}

The content property is required on pseudo-elements even if it's empty — content: '' is valid and commonly used when you just want to add a styled box rather than text.

CSS calc()

calc() lets you perform calculations in CSS — mixing different units together in ways that aren't otherwise possible.

.sidebar {
  width: calc(100% - 300px); /* full width minus sidebar */
}

.hero {
  height: calc(100vh - 80px); /* full viewport minus header */
}

clamp() — Fluid Typography

clamp() lets you set a value that scales fluidly between a minimum and maximum. It's particularly useful for font sizes that should be smaller on mobile and larger on desktop without needing media queries.

h1 {
  font-size: clamp(1.5rem, 5vw, 3rem);
  /* minimum 1.5rem, scales with viewport, maximum 3rem */
}

Advanced Selectors

CSS has a rich set of selectors beyond the basics you've already learned.

  • p:first-child — targets a p that is the first child of its parent
  • p:last-child — targets the last child
  • p:nth-child(2) — targets the second child
  • p:nth-child(odd) — targets odd numbered children
  • p:not(.special) — targets p elements that don't have the class special
  • input:checked — targets checkboxes and radio buttons that are checked
  • p + p — adjacent sibling — targets a p directly after another p
  • p ~ p — general sibling — targets all p elements after another p
  • div > p — direct child — targets p elements that are direct children of a div
