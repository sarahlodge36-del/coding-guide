Statements

A script is a series of instructions that a computer can follow one by one. Each individual instruction is called a statement. Statements should end with a semicolon — this tells the browser that the statement is complete and a new one can start.

var today = new Date();
var hourNow = today.getHours();
var greeting;

Each of those lines is a separate statement. The semicolons at the end are like full stops in a sentence — they tell JavaScript where one instruction ends and the next begins.

Comments

Just like HTML and CSS, JavaScript lets you add comments — notes that the browser ignores but that help you and other developers understand what the code does.

// This is a single line comment

/* This is a multi-line comment
   it can span several lines
   like this */

Get into the habit of writing comments as you go. Your future self will thank you when you come back to old code and have no idea what it does.

Variables

A variable is a way of storing information so you can use it later. Think of it like a labelled box — you put something inside it and give the box a name so you can find it again.

Before you can use a variable in JavaScript you need to declare it using the var keyword. You can declare a variable and assign a value to it at the same time, or declare it first and assign the value later.

var playerName = 'Sarah';
var playerHealth = 3;
var playerScore = 0;

The equals sign here doesn't mean "is equal to" — it means "store this value in this variable." That's called assignment.

var, let and const

You'll see three ways of declaring variables in JavaScript — var, let, and const. Here's the simple version of what each one means:

  • var — the original way. Works everywhere. Can be changed and redeclared. Used in older code.
  • let — the modern way for variables that will change. Can be changed but not redeclared in the same scope.
  • const — for values that will never change. If you try to change a const variable JavaScript will throw an error.
let playerName = 'Sarah'; // will change when user types their name
let playerHealth = 3; // will change as lives are lost
const gameName = 'The Code Machine Quest'; // never changes

In this guide we'll use var to keep things simple and consistent. Just know that in modern JavaScript you'll see let and const more often.

Data Types

JavaScript variables can hold different types of data. The three most common ones you'll use are:

  • Strings — text, always wrapped in quotes. Single or double quotes both work.
  • Numbers — any number, with or without a decimal point. No quotes needed.
  • Booleans — true or false. Just those two values. No quotes.
var playerName = 'Sarah'; // string
var playerHealth = 3; // number
var gameOver = false; // boolean

Arrays

An array is a special type of variable that stores a list of values rather than just one. Each item in the array is called an element. Arrays are written using square brackets with each item separated by a comma.

var inventory = []; // empty inventory
var inventory = ['Structure Crystal']; // one item
var inventory = ['Structure Crystal', 'Style Gem']; // two items

Each item in an array has an index number — its position in the list. The first item is always index 0, the second is index 1, and so on. This catches a lot of beginners out — it starts at 0, not 1!

var inventory = ['Structure Crystal', 'Style Gem', 'Logic Core'];
inventory[0]; // 'Structure Crystal'
inventory[1]; // 'Style Gem'
inventory[2]; // 'Logic Core'

Expressions and Operators

An expression evaluates into a single value. The simplest expressions just assign a value to a variable. More complex ones use operators to work something out.

var area = 3 * 2; // multiplication — result is 6
var total = 10 + 5; // addition — result is 15
var greeting = 'Hello ' + playerName; // string concatenation

That last one — joining strings together using + — is called concatenation. You'll use it all the time in JavaScript to build messages and display content.

🔨 Now Let's Build!

Open your Code Machine Quest CodePen from Chapter 20. We're going to add proper player variables to the game so JavaScript can start keeping track of who the player is and how they're doing.

In the JS panel, add these variables at the very top — before any other code:

// Game variables
var playerName = '';
var playerHealth = 3;
var playerScore = 0;
var inventory = [];
var currentRealm = 0;

// Game name — this never changes
var gameName = 'The Code Machine Quest';

Now update the button click code so it saves the player's name into the variable properly:

document.getElementById('startBtn').addEventListener('click', function() {
  var nameInput = document.getElementById('nameInput').value;
  if (nameInput === '') {
    document.getElementById('message').textContent = 'You need to enter your name, coder!';
  } else {
    playerName = nameInput;
    document.getElementById('message').textContent = 'Welcome, ' + playerName + '. Lives: ' + playerHealth + ' | Score: ' + playerScore;
  }
});

Type your name and click Begin the Quest. You should now see your name, your starting health of 3, and your starting score of 0 appear below the button.

JavaScript is now storing your name in the playerName variable and using it to build the message. The game knows who you are. 🚀

1. What is a variable?

  • a) A type of HTML element
  • b) A CSS property
  • c) A way of storing information so you can use it later
  • d) A JavaScript error

2. What is the difference between a string, a number, and a boolean?

  • a) There is no difference — they are all the same
  • b) A string is text in quotes; a number is a numeric value; a boolean is true or false
  • c) A boolean is text; a string is true or false; a number is a decimal
  • d) Numbers and booleans need quotes; strings don't

3. What index number is the first item in an array?

  • a) 1
  • b) 0
  • c) It depends on the array
  • d) There is no index number

4. What does concatenation mean in JavaScript?

  • a) Subtracting one number from another
  • b) Declaring a variable
  • c) Joining strings together using the + operator
  • d) Storing a value in a const variable

5. What is the difference between var, let, and const?

  • a) They are all identical — it doesn't matter which one you use
  • b) var is the original way; let is modern and can be changed; const is for values that never change
  • c) const can be changed; let cannot
  • d) var is for strings only; let is for numbers; const is for booleans

6. In the game we just built, what does the inventory variable store?

  • a) The player's name
  • b) The player's health
  • c) A list of items the player has collected — starting as an empty array
  • d) The current realm number
